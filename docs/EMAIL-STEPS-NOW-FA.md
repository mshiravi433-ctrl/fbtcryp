## وضعیت الان (اندازه گرفتم، حدس نزدم)

```
nameserver : ns1.vercel-dns.com / ns2.vercel-dns.com
رکورد MX   : ❌ هیچی
```

یعنی **اگر همین الان کسی به info@fbtswap.ir ایمیل بزند، برمی‌گردد.**
ورسل فقط DNS دارد، سرویس ایمیل ندارد.

## چیزی که من از قبل آماده کرده‌ام

سمت کد **کامل آماده است**. وقتی ایمیل راه افتاد، عوض کردن آدرس در کل اپ
(۱۶ جا: سه بستهٔ زبان، چهار صفحه، پرامپت هوش مصنوعی، `index.html` و…) فقط
**یک متغیر** است. لازم نیست هیچ فایلی را دست بزنی.

# 🟩 مرحلهٔ ۱ — ثبت‌نام در ImprovMX

باز کن:
```
https://app.improvmx.com/signup
```

با `fbtswap@gmail.com` ثبت‌نام کن.
**کارت بانکی نمی‌خواهد** — این مهم است، چون کارت ایرانی جواب نمی‌داد.

⏱ ۲ دقیقه

---

# 🟩 مرحلهٔ ۲ — دامنه را اضافه کن

در داشبورد ImprovMX روی **Add domain** بزن:

| فیلد | چه بنویسی |
|---|---|
| Domain | `fbtswap.ir` |
| Forward to | `fbtswap@gmail.com` |

⏱ ۱ دقیقه

> ℹ️ `.ir` در لیست دامنه‌های ممنوعِ ImprovMX **نیست** — لیستشان را خواندم،
> فقط `.tk .ml .ga .cf .gq` ممنوع‌اند.

---

# 🟩 مرحلهٔ ۳ — رکوردها را در ورسل بساز

**این مهم‌ترین مرحله است.**

در پنل **Vercel**:

1. منوی کنار → **Domains**
2. روی `fbtswap.ir` بزن
3. دکمهٔ **Add DNS Preset** (سمت راست)
4. از لیست → **ImprovMX [MX]**
5. **Add records**

تمام. ورسل خودش رکوردهای MX و SPF را می‌سازد و لازم نیست چیزی تایپ کنی.

### اگر گزینهٔ ImprovMX را در لیست پیدا نکردی

دستی بساز — این مقادیر دقیق است:

| Type | Name | Value | Priority |
|---|---|---|---|
| MX | *(خالی بگذار)* | `mx1.improvmx.com` | `10` |
| MX | *(خالی بگذار)* | `mx2.improvmx.com` | `20` |
| TXT | *(خالی بگذار)* | `v=spf1 include:spf.improvmx.com ~all` | — |

> ⚠️ **Name را خالی بگذار.** خالی یعنی خودِ `fbtswap.ir`. اگر `@` یا
> `www` بنویسی، ایمیل کار نمی‌کند.

> ⚠️ اگر رکورد MX دیگری از قبل هست، **پاکش کن**. دو MX از دو سرویس مختلف
> یعنی ایمیل‌ها گم می‌شوند.

⏱ ۵ دقیقه

معمولاً چند دقیقه، حداکثر ۲۴ ساعت.

در داشبورد ImprovMX دکمهٔ **Check Again** را بزن. وقتی نوشت:

یعنی آماده است.

**تا این تست جواب نداده، مرحلهٔ ۶ را انجام نده** — وگرنه در اپ آدرسی
می‌گذاری که ایمیل‌هایش به هیچ‌جا نمی‌رسد، و این از آدرس جی‌میل بدتر است.

⏱ ۵ دقیقه تا ۲۴ ساعت

# 🟩 مرحلهٔ ۶ — به اپ بگو (دو جا)

## ۶-الف — سایت (ورسل)

Vercel → پروژهٔ `fbtcryp-kkxi` → **Settings** → **Environment Variables** →
**Add New**:

```
Key    : VITE_SUPPORT_EMAIL
Value  : info@fbtswap.ir
```

هر سه محیط (Production / Preview / Development) را تیک بزن → Save.

بعد **Deployments** → آخرین دیپلوی → **Redeploy**.

## ۶-ب — اپ اندروید (گیت‌هاب)

GitHub → مخزن → **Settings** → **Secrets and variables** → **Actions** →
تب **Variables** → **New repository variable**:

```
Name  : VITE_SUPPORT_EMAIL
Value : info@fbtswap.ir
```

> 🔴 **حتماً تب Variables، نه Secrets.** فایل بیلد `${{ vars.* }}` می‌خواند.
> اگر Secret بسازی **بی‌صدا نادیده گرفته می‌شود**، اپ همان جی‌میل قدیمی را
> نگه می‌دارد، و تو فکر می‌کنی درست شده.

⏱ ۳ دقیقه

# 🔴 مرحلهٔ ۷ — یک خط که فقط خودت می‌توانی اضافه کنی

**این تنها قدمی است که من نتوانستم انجام دهم.** امتحان کردم، پوش شد و
گیت‌هاب ردش کرد:

```
refusing to allow a GitHub App to create or update workflow
`.github/workflows/build-apk.yml` without `workflows` permission
```

توکن من اجازهٔ دست زدن به فایل‌های `.github/workflows/` را ندارد.

### چرا این خط لازم است

Vite متغیرها را **موقع بیلد** داخل کد می‌نویسد. اگر فایل بیلد این متغیر را
رد نکند:

- ✅ سایت آدرس جدید را می‌گیرد
- ❌ **اپ اندروید روی جی‌میل قدیمی می‌ماند**

و هر دو جداگانه درست به نظر می‌رسند — بدترین حالت.

### کار کن

در گیت‌هاب این فایل را باز کن:
```
.github/workflows/build-apk.yml
```

دکمهٔ **مداد** (ویرایش) را بزن. برو **خط ۳۸**، این را می‌بینی:

```yaml
          VITE_PUBLIC_URL: ${{ vars.VITE_PUBLIC_URL }}
```

**دقیقاً زیرش** این یک خط را اضافه کن:

```yaml
          VITE_SUPPORT_EMAIL: ${{ vars.VITE_SUPPORT_EMAIL }}
```

> ⚠️ **۱۰ فاصله از اول خط** — دقیقاً هم‌تراز با خط بالایی. YAML به فاصله
> حساس است و یک فاصلهٔ کم یا زیاد کل فایل را خراب می‌کند.
> ساده‌ترین راه: خط `VITE_PUBLIC_URL` را کپی کن، زیرش بچسبان، و فقط
> اسم متغیر را عوض کن.

بعد **Commit changes** را بزن. بیلد جدید خودکار شروع می‌شود.

⏱ ۳ دقیقه

# ✅ مرحلهٔ ۸ — تست نهایی

# محدودیتی که باید بدانی

ImprovMX رایگان **فقط دریافت** می‌کند:

- ✅ کسی به `info@fbtswap.ir` می‌نویسد → داخل جی‌میلت می‌آید
- ❌ جواب بدهی → گیرنده آدرس **جی‌میل** تو را می‌بیند

## راه‌حل رایگانش (اختیاری، بعداً)

جی‌میل → تنظیمات → `Accounts and Import` → `Send mail as` →
`Add another email address` → `info@fbtswap.ir`

یک کد تأیید می‌فرستد که چون forwarding فعال است **داخل همان جی‌میل می‌آید**.
کد را بزن. از آن به بعد می‌توانی فرستنده را `info@fbtswap.ir` بگذاری.
