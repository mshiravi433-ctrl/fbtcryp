# چهار کار باقی‌مانده — کاملاً دقیق

سایت درست شد ✅ حالا فقط چهار مقدار مانده.

سرور همین الان می‌گوید دقیقاً چه چیزی کم است:

```
web  → VITE_VAPID_PUBLIC_KEY و VAPID_PRIVATE_KEY  اصلاً ست نشده‌اند
fcm  → FIREBASE_PRIVATE_KEY ست شده ولی مقدارش غلط است (۴۰ کاراکتر)
cron → CRON_SECRET ست نشده
```

پس: **سه تا اضافه می‌کنی، یکی را تصحیح می‌کنی.**

## جایی که هر چهار مقدار می‌رود

هر بار همین مسیر:

```
vercel.com  →  پروژهٔ fbtcryp-kkxi  →  Settings  →  Environment Variables
```

**برای اضافه کردن یک متغیر نو:**
دکمهٔ **Add New** → **Key** و **Value** را پر کن → **هر سه تیک** (Production ✅ Preview ✅ Development ✅) → **Save**

**برای تصحیح یکی که از قبل هست:**
در لیست پیدایش کن → **⋮** کنارش → **Edit** → مقدار را عوض کن → **Save**

> ⚠️ اگر تیک **Production** نخورد، سایت اصلی آن را نمی‌بیند و هیچ خطایی هم نمی‌دهد.

# کار ۱ — تصحیح `FIREBASE_PRIVATE_KEY`

**این تنها موردی است که از قبل ست شده ولی مقدارش غلط است.**

## چرا غلط است

سرور گزارش می‌دهد مقدار فعلی **۴۰ کاراکتر** است. مقدار درست حدود **۱۷۰۰ کاراکتر** است.

۴۰ کاراکتر دقیقاً طول `private_key_id` است — یعنی خط بالایی را کپی کرده‌ای.

## کلید نو بساز (چون قبلی در چت لو رفته)

**۱.** برو به `console.cloud.google.com/iam-admin/serviceaccounts`

**۲.** بالای صفحه پروژهٔ **`fbt-room-a46fc`** را انتخاب کن

**۳.** روی این ردیف بزن:
`firebase-adminsdk-fbsvc@fbt-room-a46fc.iam.gserviceaccount.com`

**۴.** تب **KEYS**

**۵.** کلیدی که با `dd3e2f8a` شروع می‌شود → **🗑 Delete** → تأیید

**۶.** **ADD KEY** → **Create new key** → **JSON** → **CREATE**

فایل در Downloads دانلود می‌شود.

## مقدار درست را بردار

فایل را با ویرایشگر متن باز کن. این دو خط کنار هم‌اند:

```json
"private_key_id": "dd3e2f8a0523ec5103df0d304abfff716e70d976",
"private_key": "-----BEGIN PRIVATE KEY-----\nMIIEvQIBADANBgkqhkiG9w0BAQEFAASCBKcw...\n-----END PRIVATE KEY-----\n",
```

خط **دوم** را می‌خواهی — آن که با `-----BEGIN` شروع می‌شود.

✅ از `-----BEGIN PRIVATE KEY-----` تا `-----END PRIVATE KEY-----\n`
✅ آن `\n`ها را همان‌طور که هستند بگذار — تست کردم، سرور هر دو حالت (`\n` تایپ‌شده یا Enter واقعی) را قبول می‌کند
✅ گیومهٔ `"` اول و آخر را اگر اشتباهی کپی کردی هم مشکلی نیست — تست کردم، سرور تحمل می‌کند

**تنها چیزی که واقعاً مهم است: باید آن رشتهٔ بلندِ `BEGIN`دار باشد، نه هگز کوتاه.**

| Key | Value |
|---|---|
| `FIREBASE_PRIVATE_KEY` | کل مقدار `private_key` |

> همان‌جا چک کن `FIREBASE_PROJECT_ID` = `fbt-room-a46fc` و
> `FIREBASE_CLIENT_EMAIL` = مقدار `client_email` باشد.
> سرور می‌گوید این دو درست‌اند، ولی چون فایل نو ساختی یک نگاه بینداز.

# کار ۲ و ۳ — دو کلید VAPID

**این دو اصلاً ست نشده‌اند.** هر دو از یک صفحه می‌آیند.

**۱.** برو به `console.firebase.google.com`

**۲.** پروژهٔ **`fbt-room-a46fc`**

**۳.** بالا سمت چپ، کنار «Project Overview» یک **⚙️** هست → بزن → **Project settings**

**۴.** تب **Cloud Messaging**

**۵.** اسکرول پایین تا بخش **Web Push certificates**

**۶.** اگر ردیفی هست: **⋮** → **Delete** (چون در چت لو رفته)
سپس **Generate key pair** را بزن

حالا یک جدول با دو ستون می‌بینی:

| Key در ورسل | از کدام ستون |
|---|---|
| `VITE_VAPID_PUBLIC_KEY` | **Key pair** — رشتهٔ بلند، ۸۷ کاراکتر، با `B` شروع می‌شود |
| `VAPID_PRIVATE_KEY` | **Private key** — کوتاه‌تر، ۴۳ کاراکتر |

> ⚠️ به دومی **هرگز** `VITE_` اضافه نکن. هر متغیر با پیشوند `VITE_` داخل
> جاوااسکریپتی که همهٔ کاربران دانلود می‌کنند کامپایل می‌شود — یعنی منتشر می‌شود.
> اولی عمداً `VITE_` دارد چون قرار است عمومی باشد. آن درست است.

**اختیاری ولی مفید:**

| Key | Value |
|---|---|
| `VAPID_SUBJECT` | `mailto:` + ایمیل خودت، مثلاً `mailto:mshiravi433@gmail.com` |

# تست

```
https://www.lawpoetics.ir/api/cron/status
```

**باید این را ببینی:**

```json
{"web":{"configured":true,"subscribers":0,"missing":[]},
 "fcm":{"configured":true,"devices":0,"missing":[]},
 "cronSecretSet":true,"durableStorage":true,"canSend":false}
```

سه چیز را نگاه کن:
- `web.configured` → `true`
- `fcm.configured` → `true` و فیلد `problem` **ناپدید شده باشد**
- `cronSecretSet` → `true`

`subscribers` و `devices` صفر و `canSend` هم `false` می‌ماند — **این طبیعی است.**
یعنی هنوز هیچ دستگاهی نوتیفیکیشن را روشن نکرده.

**تست واقعی:** در اپ برو تنظیمات ← نوتیفیکیشن ← روشن کن.
دوباره آدرس را باز کن: حالا `devices` باید `1` شود و `canSend` بشود `true`.
