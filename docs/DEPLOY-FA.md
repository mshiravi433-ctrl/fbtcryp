## مرحله ۱ — کیف پول متامسک

برای دیپلوی به یک کیف پول با کمی BNB نیاز داری. این کیف پول **مالک قرارداد**
می‌شود.

> ⚠️ **مهم:** از کیف پولی استفاده کن که فقط برای همین کار باشد. کیف پول اصلی
> و پرپولت را وارد Remix نکن. بعداً در مرحله ۵ مالکیت را منتقل می‌کنیم.

### ۱.۱ نصب متامسک

1. از Google Play یا App Store اپ **MetaMask** را نصب کن
   (سازنده: MetaMask، لوگوی روباه نارنجی)
2. باز کن → **Create a new wallet**
3. رمز عبور بگذار
4. **۱۲ کلمه بازیابی** را روی کاغذ بنویس

> 🔴 آن ۱۲ کلمه را در گالری عکس نگیر، در تلگرام سیو نکن، و برای هیچ‌کس نفرست.
> هرکس آن‌ها را داشته باشد صاحب تمام پول داخل کیف پول است. من هم اگر ازت
> بخواهم، نباید بدهی.

### ۱.۲ اضافه کردن شبکه BNB

متامسک به‌صورت پیش‌فرض روی اتریوم است. باید BNB را اضافه کنی:

1. بالای صفحه روی اسم شبکه (**Ethereum Mainnet**) بزن
2. **Add network** → پایین صفحه **Add a network manually**
3. این مقادیر را دقیقاً وارد کن:

| فیلد | مقدار |
|---|---|
| Network name | `BNB Smart Chain` |
| RPC URL | `https://bsc-dataseed.binance.org` |
| Chain ID | `56` |
| Currency symbol | `BNB` |
| Block explorer | `https://bscscan.com` |

4. **Save** بزن

### ۱.۳ خرید و ارسال BNB

حدود **۰.۰۲ BNB** (تقریباً ۱۲ دلار) کافی است و ته‌مانده‌اش برایت می‌ماند.

- آدرس کیف پول متامسک را کپی کن (بالای صفحه، `0x…`)
- از یک صرافی (نوبیتکس، والکس، بایننس…) BNB بخر
- موقع برداشت حتماً شبکه **BEP20 / BNB Smart Chain** را انتخاب کن

> 🔴 اگر شبکه را اشتباه انتخاب کنی (مثلاً ERC20 یا BEP2) پول گم می‌شود و
> برگشت‌پذیر نیست. حتماً **BEP20** باشد.

منتظر بمان تا موجودی در متامسک ظاهر شود.

## مرحله ۲ — تمرین روی تست‌نت (رایگان)

قبل از خرج کردن پول واقعی، همین کار را با پول تقلبی تمرین می‌کنیم. اگر جایی را
اشتباه بروی، هیچ ضرری ندارد.

**اگر عجله داری می‌توانی این مرحله را رد کنی**، ولی خیلی توصیه می‌کنم انجامش
بدهی — یک‌بار تمرین، جلوی اشتباه گران‌قیمت را می‌گیرد.

### ۲.۱ اضافه کردن شبکه تست

در متامسک، مثل قبل یک شبکه دستی اضافه کن:

| فیلد | مقدار |
|---|---|
| Network name | `BSC Testnet` |
| RPC URL | `https://data-seed-prebsc-1-s1.binance.org:8545` |
| Chain ID | `97` |
| Currency symbol | `tBNB` |
| Block explorer | `https://testnet.bscscan.com` |

### ۲.۲ گرفتن BNB تقلبی رایگان

1. برو به: **testnet.bnbchain.org/faucet-smart**
2. آدرس متامسکت را paste کن
3. **Send** بزن → چند دقیقه بعد ۰.۱ tBNB می‌گیری

### ۲.۳ تمرین

حالا مرحله ۳ را کامل انجام بده، فقط با این تفاوت‌ها:

- در متامسک شبکه را روی **BSC Testnet** بگذار
- به‌جای آدرس روتر پنکیک‌سواپ مین‌نت، این را بگذار:
  `0xD99D1c33F9fC3444f8101754aBC46c52416550D1`

وقتی موفق شدی، برگرد به مین‌نت و دوباره انجامش بده.

## مرحله ۳ — دیپلوی واقعی

### ۳.۱ باز کردن Remix

Remix یک محیط برنامه‌نویسی داخل مرورگر است. چیزی نصب نمی‌شود.

1. مرورگر **Chrome** را باز کن (نه اپ متامسک، مرورگر معمولی)
2. برو به: **remix.ethereum.org**
3. منوی سه‌نقطه مرورگر → گزینه **Request desktop site** را بزن

> این مرحله را رد نکن. بدون حالت دسکتاپ، دکمه‌های Remix روی موبایل درست
> نمایش داده نمی‌شوند.

4. صفحه که بالا آمد، اگر پنجره خوش‌آمدگویی آمد ببندش

### ۳.۲ ساختن فایل قرارداد

1. در ستون چپ، آیکون **File explorer** (شبیه برگه کاغذ، بالاترین آیکون) را بزن
2. زیر پوشه `contracts` روی آیکون **صفحه سفید با علامت +** بزن
   (Create new file)
3. اسم فایل را بگذار:

```
FeeRouter.sol
```

4. Enter بزن

### ۳.۳ کپی کردن کد قرارداد

1. در یک تب جدید مرورگر، فایل قرارداد را باز کن:

   **github.com/mshiravi433-ctrl/fbtcryp/blob/arena/019fa427-fbtcryp/contracts/FeeRouter.sol**

2. بالای کد، دکمه **Copy raw file** (آیکون دو مربع روی هم) را بزن
3. برگرد به تب Remix
4. داخل فایل خالی `FeeRouter.sol` بزن و **paste** کن
5. مطمئن شو خط اول این است:

```solidity
// SPDX-License-Identifier: MIT
```

و آخرین خط `}` تنها باشد. اگر کد ناقص paste شده، دوباره امتحان کن.

### ۳.۴ کامپایل کردن

«کامپایل» یعنی تبدیل کد به زبان قابل فهم بلاکچین.

1. در ستون چپ، آیکون **Solidity Compiler** را بزن
   (شبیه لوگوی Solidity، آیکون دوم از بالا)
2. این تنظیمات را دقیقاً اعمال کن:

| تنظیم | مقدار |
|---|---|
| COMPILER | `0.8.26` را از لیست انتخاب کن |
| Language | `Solidity` |
| EVM Version | روی **`paris`** بگذار |
| Enable optimization | تیک بزن، عدد `200` |

> ⚙️ **چرا `paris`؟** نسخه‌های جدیدتر EVM دستوراتی دارند که ممکن است روی
> شبکه BNB پشتیبانی نشوند و قرارداد خراب شود. من قرارداد را با `paris`
> تست کرده‌ام، پس همین را بگذار.

3. دکمه آبی **Compile FeeRouter.sol** را بزن
4. چند ثانیه صبر کن

**نتیجه درست:** روی آیکون Solidity Compiler یک **تیک سبز** ظاهر می‌شود.

اگر خطای قرمز دیدی، به بخش [مشکلات رایج](#مشکلات-رایج) برو.

> 💡 ممکن است چند پیام **زرد** (warning) ببینی. اشکالی ندارد، فقط قرمز مهم است.

### ۳.۵ وصل کردن متامسک

1. در ستون چپ آیکون **Deploy & run transactions** را بزن
   (آیکون سوم، شبیه فلش رو به راست)
2. در بالای پنل، منوی **ENVIRONMENT** را باز کن
3. گزینه **Injected Provider - MetaMask** را انتخاب کن
4. متامسک باز می‌شود → **Connect** را بزن

**چک کن که درست وصل شده:**

- زیر ENVIRONMENT باید بنویسد: `Custom (56) network`
  (اگر تست‌نت هستی: `Custom (97) network`)
- در فیلد **ACCOUNT** آدرس متامسکت را ببینی

> اگر عدد ۵۶ نبود، در متامسک شبکه را به BNB Smart Chain عوض کن و صفحه Remix
> را رفرش کن.

### ۳.۶ وارد کردن سه پارامتر

این حساس‌ترین قسمت است. با دقت انجام بده.

1. در بخش **CONTRACT**، مطمئن شو `FeeRouter - contracts/FeeRouter.sol`
   انتخاب شده
2. کنار دکمه نارنجی **Deploy** یک فلش کوچک ▸ هست — بزنش تا باز شود
3. سه فیلد ظاهر می‌شود. دقیقاً این‌ها را وارد کن:

**فیلد اول — `_dexRouter`:**

```
0x10ED43C718714eb63d5aA57B78B54704E256024E
```
> آدرس روتر پنکیک‌سواپ. برای تست‌نت به‌جایش
> `0xD99D1c33F9fC3444f8101754aBC46c52416550D1` بگذار.

**فیلد دوم — `_feeRecipient`:**

```
0xaf5CE154cEfd22Da5BD1D0a54479E81963A224d6
```
> کیف پول خودت که کارمزد به آن می‌ریزد.

**فیلد سوم — `_feeBps`:**

```
50
```
> یعنی ۵۰ در ده‌هزار = **۰.۵٪**. (اگر مثلاً ۱٪ می‌خواستی `100` می‌گذاشتی.
> بیشتر از ۱۰۰ را خود قرارداد قبول نمی‌کند.)

> 🔴 **قبل از ادامه دو بار چک کن.** مخصوصاً فیلد دوم — اگر اشتباه باشد،
> کارمزدها به آدرس اشتباه می‌رود. (البته بعداً با `setFeeRecipient` قابل
> تغییر است، ولی بهتر است از اول درست باشد.)

### ۳.۷ دیپلوی

1. دکمه نارنجی **Deploy** را بزن (یا **transact**)
2. متامسک باز می‌شود و کارمزد را نشان می‌دهد (حدود ۰.۰۰۲ تا ۰.۰۱ BNB)
3. **Confirm** بزن
4. ۱۰ تا ۳۰ ثانیه صبر کن

**نتیجه درست:** پایین صفحه Remix، در بخش **Deployed Contracts**، قراردادت
ظاهر می‌شود: `FEEROUTER AT 0X...`

### ۳.۸ کپی کردن آدرس قرارداد 🎯

**این مهم‌ترین خروجی کل فرآیند است.**

1. در بخش **Deployed Contracts**، کنار `FEEROUTER AT 0X...` یک
   **آیکون کپی** (دو مربع) هست
2. بزنش — آدرس قرارداد کپی می‌شود
3. **همین الان جایی امن ذخیره‌اش کن** (یادداشت، برای خودت در تلگرام بفرست)

آدرسی شبیه این خواهد بود:

```
0x1a2B3c4D5e6F7a8B9c0D1e2F3a4B5c6D7e8F9a0B
```

> ⚠️ **این آدرس با آدرس کیف پولت فرق دارد!**
> - `0xaf5CE154…24d6` = کیف پول تو (کارمزد اینجا می‌ریزد)
> - آدرس جدید = قرارداد (این را در اپ تنظیم می‌کنیم)
>
> این دو را قاطی نکن.

### ۳.۹ تست سریع قرارداد

قبل از ادامه، مطمئن شو قرارداد درست کار می‌کند:

1. روی نام قرارداد در **Deployed Contracts** بزن تا باز شود
2. دکمه آبی **feeRecipient** را بزن
   → باید آدرس کیف پولت را نشان دهد: `0xaf5CE154...`
3. دکمه آبی **feeBps** را بزن
   → باید `50` نشان دهد

اگر این دو درست بودند، قرارداد سالم است. ✅

## مرحله ۴ — وصل کردن به اپ

الان قرارداد وجود دارد ولی اپ از آن خبر ندارد.

1. در مرورگر برو به مخزن گیت‌هاب:
   **github.com/mshiravi433-ctrl/fbtcryp**
2. تب **Settings** (بالای صفحه)
3. از منوی چپ: **Secrets and variables** → **Actions**
4. تب **Variables** را بزن (نه Secrets)
5. دکمه **New repository variable**
6. پر کن:

| فیلد | مقدار |
|---|---|
| Name | `VITE_FEE_ROUTER_ADDRESS` |
| Value | آدرس قراردادی که در ۳.۸ کپی کردی |

7. **Add variable**

حالا اپ را دوباره build کن:

- تب **Actions** → **Build Android APK** → **Run workflow** → **Run workflow**

APK جدیدی که ساخته می‌شود کارمزد را فعال دارد.

> از این لحظه، هر سواپی که کاربران در اپ انجام دهند، ۰.۵٪ آن به کیف پول تو
> واریز می‌شود.

## مرحله ۵ — امن‌سازی

### ۵.۱ Verify کردن قرارداد در BscScan

این کار باعث می‌شود کاربران بتوانند کد قرارداد را ببینند. برای اعتماد ضروری
است — کاربر باهوش به قرارداد verify نشده approve نمی‌دهد.

1. برو به `bscscan.com/address/آدرس_قراردادت`
2. تب **Contract** → لینک **Verify and Publish**
3. پر کن:

| فیلد | مقدار |
|---|---|
| Compiler Type | `Solidity (Single file)` |
| Compiler Version | `v0.8.26+commit.8a97fa7a` |
| License | `MIT` |

4. **Continue**
5. کد قرارداد را کامل paste کن
6. **Optimization**: `Yes`، **Runs**: `200`
7. در قسمت Misc Settings، **EVM Version** را روی `paris` بگذار
8. **Verify and Publish**

اگر همه تنظیمات دقیقاً مثل بالا باشد، چند ثانیه بعد تیک سبز می‌گیری.

### ۵.۲ انتقال مالکیت (مهم)

الان کیف پول متامسک روی گوشیت مالک قرارداد است. اگر گوشی گم شود یا ویروس
بگیرد، کسی می‌تواند آدرس گیرنده کارمزد را عوض کند.

**بعد از اینکه مطمئن شدی همه‌چیز کار می‌کند:**

در Remix، در قرارداد دیپلوی‌شده:
1. فیلد کنار **transferOwnership** را پیدا کن
2. آدرس یک کیف پول امن‌تر را وارد کن (کیف پول سخت‌افزاری یا یک متامسک دیگر
   که فقط روی دستگاه امن است)
3. **transact** بزن

> ⚠️ این کار برگشت‌ناپذیر است. اگر آدرس اشتباه بزنی، کنترل قرارداد را
> برای همیشه از دست می‌دهی. حتماً آدرسی بزن که مطمئنی به آن دسترسی داری.

### ۵.۳ اولین معامله واقعی را کوچک بزن

قبل از اینکه به کسی اپ را معرفی کنی:

1. اپ را باز کن، کیف پول وصل کن
2. یک سواپ خیلی کوچک بزن (مثلاً ۱ دلار)
3. برو به `bscscan.com/address/0xaf5CE154cEfd22Da5BD1D0a54479E81963A224d6`
4. باید ببینی مبلغ کوچکی به کیف پولت واریز شده ✅

اگر این کار کرد، همه‌چیز درست است.

## مشکلات رایج

### در Remix دکمه‌ها را نمی‌بینم
حالت **Request desktop site** را روشن نکرده‌ای. منوی سه‌نقطه مرورگر → تیک بزن.

### موقع Compile خطای قرمز می‌گیرم
- نسخه کامپایلر باید دقیقاً `0.8.26` باشد
- کد ناقص paste شده — کل فایل را دوباره کپی کن
- خط اول باید `// SPDX-License-Identifier: MIT` باشد

### `Injected Provider` در لیست نیست
متامسک وصل نیست. مرورگرت باید متامسک را ببیند. اگر نشد، از **مرورگر داخلی
خود اپ متامسک** استفاده کن: اپ متامسک → منوی همبرگری → Browser → آدرس
`remix.ethereum.org` را بزن.

### نوشته `Custom (1) network` به‌جای ۵۶
در متامسک روی شبکه اتریوم هستی. شبکه را به **BNB Smart Chain** عوض کن و
صفحه Remix را رفرش کن.

### خطای `insufficient funds for gas`
BNB کافی نداری. حداقل ۰.۰۲ BNB روی شبکه BEP20 بفرست.

### تراکنش خیلی طول کشید یا `pending` ماند
شبکه شلوغ است. در متامسک تراکنش را **Speed up** کن، یا صبر کن.

### `Gas estimation failed`
معمولاً یعنی یکی از سه پارامتر اشتباه است:
- آدرس‌ها باید `0x` داشته باشند و ۴۲ کاراکتر باشند
- `_feeBps` باید عدد باشد (`50`)، نه متن
- هیچ فیلدی نباید خالی باشد

### کارمزد به کیف پولم نمی‌رسد
- چک کن `VITE_FEE_ROUTER_ADDRESS` را **آدرس قرارداد** گذاشته باشی، نه آدرس
  کیف پول
- بعد از تنظیم متغیر، حتماً APK را دوباره build کرده باشی
- در Remix دکمه `feeRecipient` را بزن و مطمئن شو آدرس درست است

## خلاصه در یک نگاه

| مقدار | چیست |
|---|---|
| `0x10ED43C718714eb63d5aA57B78B54704E256024E` | روتر پنکیک‌سواپ (پارامتر ۱) |
| `0xaf5CE154cEfd22Da5BD1D0a54479E81963A224d6` | کیف پول تو (پارامتر ۲) |
| `50` | یعنی ۰.۵٪ (پارامتر ۳) |
| `0.8.26` | نسخه کامپایلر |
| `paris` | نسخه EVM |
| `200` | optimizer runs |

**سه چیزی که نباید قاطی شوند:**

1. **کیف پول تو** `0xaf5C…24d6` — کارمزد اینجا می‌آید
2. **آدرس قرارداد** (بعد از دیپلوی می‌گیری) — در گیت‌هاب تنظیم می‌شود
3. **کلید خصوصی / ۱۲ کلمه** — هرگز جایی وارد نکن

## یک تذکر صادقانه

من این قرارداد را نوشتم و در یک EVM واقعی تست کردم: دقیقاً ۰.۵٪ در هر سه
حالت سواپ جمع می‌شود، سقف ۱٪ رعایت می‌شود و کسی جز مالک نمی‌تواند تنظیمات را
عوض کند.

ولی این با **ادیت حرفه‌ای** فرق دارد. تست‌های من ثابت می‌کنند کارمزد کار
می‌کند؛ ثابت نمی‌کنند که قرارداد در برابر هر نوع حمله‌ای مصون است. اگر قرار
است حجم قابل‌توجهی پول از این قرارداد رد شود، قبلش یک ادیت حرفه‌ای بگیر.

همچنین: گرفتن کارمزد یعنی این یک سرویس مالی تجاری است. بررسی کن این کار برای
شرکت FBT iran چه الزامات مجوزی و مالیاتی دارد.
