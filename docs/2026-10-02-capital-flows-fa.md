# جریان سرمایه و سود گزارش‌شده — جایگزینیِ کارت‌های «خوانده نشد» با منبع واقعی

تاریخ: 2026-10-02  
وضعیت: پیاده‌سازی شده — فقط خواندنی، بدون معامله، بدون کلیدِ حساس

## خلاصه

گزارش کاربر: در تب‌های «هوشمندی» و «FBT جهانی» صفحهٔ خبرها، کارت‌های
«ورود سرمایه سهام و کریپتو به کشور»، «سودده‌ترین شرکت»، «بیشترین و کمترین
خروج ۲۴ ساعته»، «برترین‌های اقتصاد جهانی»، «شاخص سهام» و «منحنی بازده
آمریکا» خالی بودند یا «در این دور خوانده نشد.» می‌گفتند.

علت، کمبود داده نبود؛ **نبودِ منبعِ وصل‌شده** بود. آن کارت‌ها عمداً خالی
می‌ماندند چون قاعدهٔ پروژه این است که عددِ بدون منبع ساخته نشود. راه‌حل،
وصل کردن سه منبعِ عمومیِ رایگان و بدون کلید است که دقیقاً همان چیزی را
می‌دهند که کارت ادعا می‌کند — به‌علاوهٔ یک میزِ کلانِ بدون کلید (FRED CSV) و
آلفا ونتیج به‌عنوان **آخرین** پله.

| کارت | منبعِ واقعیِ جدید | چه چیزی اندازه گرفته می‌شود |
|------|-------------------|------------------------------|
| جذب سرمایه ۲۴ ساعته (جای «ورود سرمایه به کشور») | CoinGecko `/coins/markets` | `market_cap_change_24h` — دلاری که به ارزش‌گذاری دارایی اضافه/کم شده |
| عرضهٔ کل استیبل‌کوین | DefiLlama `/stablecoins` | عرضهٔ در گردش و اختلاف آن با دیروز/هفتِ پیش — استیبل‌کوین با پولِ واقعی ضرب و با خروجِ آن سوزانده می‌شود |
| بیشترین ورود/خروج به زنجیره | DefiLlama `chainCirculating` | اختلاف عرضهٔ هر زنجیره با دیروز، به تفکیک زنجیره |
| بیشترین خروج سرمایه ۲۴ ساعته | CoinGecko | بدترین `market_cap_change_24h` |
| سودده‌ترین شرکت | SEC EDGAR XBRL frames | `NetIncomeLoss` گزارش‌شدهٔ فصلی + لینکِ خودِ گزارش |
| شاخص سهام | stooq → yahoo → **آلفا ونتیج** (SPY/QQQ) | قیمتِ واقعیِ ETF، با برچسبِ ETF |
| منحنی بازده آمریکا | **FRED CSV بدون کلید** (`T10Y2Y`, `DGS2`, `DGS10`, `DGS30`) → FRED کلیددار → آلفا ونتیج | بازدهِ واقعیِ خزانه‌داری آمریکا |

## چرا «ورود سرمایه به کشور» تبدیل شد به «جذب سرمایه»

هیچ منبعِ عمومیِ تأییدشده‌ای جریانِ سرمایهٔ سهام + کریپتو را **به تفکیک
کشور** منتشر نمی‌کند؛ هر عددی در آن کارت یا ساختگی بود یا از یک گزارشِ
پولیِ غیرقابل‌راستی‌آزمایی. طبق خواستهٔ کاربر، کارت با یک سنجهٔ واقعیِ
قابل‌خواندن جایگزین شد: **دارایی‌هایی که در ۲۴ ساعت گذشته بیشترین سرمایه
را جذب کرده‌اند** (و در کنارش، خالصِ عرضهٔ استیبل‌کوین که پولِ نقدِ واقعیِ
وارد/خارج‌شده به بازار کریپتو است). کلیدهای قدیمی (`insights.countryFlow`,
`insights.capitalOutflow`) نگه داشته شدند تا رشته‌های تست و ارجاع‌ها
نشکنند، اما متن‌شان در هر ۱۲ زبان به سنجهٔ واقعی تغییر کرد.

## Endpointها

| Method | Path | کش |
|--------|------|-----|
| GET | `/api/insights/flows` | ۱۵ دقیقه (`stale-while-revalidate` یک ساعت) |
| GET | `/api/insights/flows/status` | ۶۰ ثانیه |

پاسخ همیشه همان schema است (`fbt.capital-flows.v1`)؛ سه بخش **مستقل** از هم
شکست می‌خورند:

```
{ ok, schema, at, liveSections, stale, cached, readOnly: true, executes: false,
  tokenFlows:   { status, source, at, count, topInflow, topOutflow, inflows[5], outflows[5], totals },
  chainFlows:   { status, source, at, totalCirculatingUsd, net24hUsd, net24hPct, net7dUsd,
                  assets, topInflowChain, topOutflowChain, chainInflows, chainOutflows, topAssets },
  profitLeaders:{ status, source, period, taxonomy, tag, label, facts, companies,
                  top, leaders[5], weakest } }
```

بخشِ خاموش ⇒ `{ status: 'UNAVAILABLE', reason, detail }` و **بدون هیچ ردیف**.
`ok:false` فقط وقتی است که هر سه بخش خاموش باشند؛ آن‌وقت هم HTTP 503 با همان
schema برمی‌گردد تا پنل سه جای خالیِ صادقانه نشان دهد، نه یک پنلِ شکسته.

کدهای دلیل: `RATE_LIMITED` (۴۲۹)، `UPSTREAM_HTTP_5XX`، `UPSTREAM_HTTP_4XX`،
`RPC_TIMEOUT`، `NETWORK_UNAVAILABLE`، `NO_REPORTED_PROFIT_FRAME`. `detail`
حداکثر ۱۶۰ نویسه است و هرگز URL یا بدنهٔ upstream را حمل نمی‌کند.

هیچ‌کدام از این سه منبع کلید نمی‌خواهند. این متغیرها فقط تنظیم‌اند:

| نام | پیش‌فرض | توضیح |
|-----|---------|--------|
| `CAPITAL_FLOWS_TIMEOUT_MS` | `12000` | تایم‌اوت هر upstream |
| `CAPITAL_FLOWS_COIN_PAGE_SIZE` | `250` | اندازهٔ صفحهٔ CoinGecko (بیشینه ۲۵۰) |
| `CAPITAL_FLOWS_MIN_CHAIN_USD` | `1000000` | زنجیرهٔ کوچک‌تر از این نمی‌تواند صدرنشینِ جریان شود |
| `DEFILLAMA_STABLECOINS_BASE` | `https://stablecoins.llama.fi` | |
| `SEC_EDGAR_BASE` | `https://data.sec.gov` | |
| `SEC_EDGAR_USER_AGENT` | `fbt-swap-app/1.0 (read-only market intelligence; …)` | SEC از کلاینتِ بی‌نام ۴۰۳ می‌گیرد |
| `MACRO_TOPUP_TIMEOUT_MS` | `3500` | تایم‌اوت هر درخواستِ پلهٔ تکمیل |
| `MACRO_TOPUP_DEADLINE_MS` | `5000` | سقفِ کلِ فاز تکمیل (زیرِ تایم‌اوت ۸ ثانیه‌ای global-intel) |
| `ALPHA_VANTAGE_MACRO_DAILY_BUDGET` | `6` | سقفِ روزانهٔ این میز از کلیدِ ۲۵/روز |
| `ALPHA_VANTAGE_MACRO_MAX_PER_PASS` | `4` | بیشترین نماد در یک پاسِ سرد |
| `ALPHA_VANTAGE_MIN_SPACING_MS` | `1100` | فاصلهٔ اجباریِ ≥۱ ثانیه (محدودیت burst رایگان) |
| `ALPHA_VANTAGE_MACRO_CACHE_MS` | `43200000` | ۱۲ ساعت کش برای هر سری |
| `FRED_API_KEY` | — | اختیاری؛ بدون آن هم `fredgraph.csv` بدون کلید خوانده می‌شود |

کلیدِ Alpha Vantage که کاربر داد در `.env` (git-ignore) گذاشته شد و برای
استقرار باید در متغیرهای محیطِ Vercel تنظیم شود. این کلید **هرگز** در
`.env.example`، در کد سرور، در کد کلاینت یا در هیچ پاسخِ API نمی‌آید.

## ترتیب میزهای کلان (server/macroData.js)

```
stooq → yahoo → fredcsv (بدون کلید) → fred (با کلید، فقط اگر FRED_API_KEY باشد)
      → av (آلفا ونتیج، فقط برای نمادهایی که هیچ میزی نداد)
```

- **اولین خوانش برنده است**: میزِ تکمیل هرگز خوانشِ میزِ قبلی را
  بازنویسی نمی‌کند (`mergeItems`).
- هر ابزار `source` خودش را نگه می‌دارد (`stooq:DX.F`, `fredcsv:DGS10`,
  `av:SPY`)؛ پاکتِ بیرونی ترکیب را می‌گوید: `macroData:stooq+topup`.
- **SPY/QQQ به‌جای SPX/NDX جعل نمی‌شوند**: یک ETF با نامِ خودش و واحد
  `USD/share` و `kind: 'equity'` نمایش داده می‌شود.
- آلفا ونتیج **آخرین** پله است، سریال (نه موازی)، با بودجهٔ روزانهٔ سخت؛
  یک پاسخِ `Note`/`Information` بودجهٔ همان روز را می‌بندد تا بقیهٔ پاس
  به دیوار نکوبد. تمام‌شدنِ بودجه یک skipِ بی‌صداست، نه خطا.
- اگر هیچ میزی ≥۳ ابزار ندهد ⇒ `throw NO_MACRO_DATA_SOURCE`؛ موتورِ
  global-intel آن را به `UNAVAILABLE` صادقانه تبدیل می‌کند.

## مرزهای صداقت (بدون تغییر)

- عددِ بدون منبع ساخته نمی‌شود: کارتِ بی‌داده همان «خوانده نشد» می‌ماند و
  دلیلش را می‌گوید.
- «صدرنشینِ ورود سرمایه» فقط وقتی وجود دارد که واقعاً یک **افزایش** باشد؛
  در بازاری که همه منفی‌اند، کارت ورود خالی می‌ماند (نه «کمترین بازنده»).
- رتبه‌بندیِ سود فقط گزارش‌هایی با دورهٔ سه‌ماهه (≤۱۰۰ روز) را می‌پذیرد تا
  رقمِ نیم‌ساله با رقمِ فصلی مقایسه نشود؛ هر CIK یک بار، با آخرین accession.
- هر عددِ سود، لینکِ همان گزارشِ SEC را دارد.
- تغییرِ ارزش بازار ≠ حجم معاملات ≠ سودِ شرکت؛ متنِ هر کارت همین را می‌گوید.
- روزهای تعطیل/نیامده در FRED (سلولِ خالی یا `.`) **دادهٔ غایب** است، نه صفر.
- این مسیرها فقط می‌خوانند: هیچ امضا، هیچ تراکنش، هیچ کلیدی در کلاینت.

## سمت کلاینت

- `src/lib/capitalFlows.js` — یک fetcher با کشِ ۵ دقیقه‌ای و single-flight؛
  دو پنل (هوشمندی و FBT جهانی) از **یک** درخواست در هر پنجره استفاده
  می‌کنند. fallback آفلاین عمداً ندارد: ردیفِ جعلی بهتر از جای خالی نیست.
- `src/lib/marketInsights.js` — `deriveMarketInsights({ markets, equities,
  news, flows })` کلیدهای `capitalInflow`, `capitalOutflowToken`,
  `capitalTotals`, `stablecoinNet`, `chainInflow`, `chainOutflow`,
  `profitLeader`, `profitLeaders`, `flowsAt`, `flowsStale` را برمی‌گرداند؛
  سه کلیدِ قدیمیِ `countryFlow` / `capitalOutflow` / `companyProfit` همان
  شکلِ `{ available, reason }` را نگه داشته‌اند.
- `src/components/MarketInsightsPanel.jsx` — شش کارتِ `ValueCard` + دو فهرستِ
  رتبه‌بندی (ورود/خروج) + فهرستِ سودده‌ترین‌ها با لینکِ گزارش؛ دکمهٔ
  «تلاش دوباره» بین `retryEquities` و `retryFlows` جابه‌جا می‌شود و پیامِ
  `insights.flowSourceDown` وقتی می‌آید که `flows.ok === false` باشد.
- `src/components/ai/AiGlobalIntelligence.jsx` — `EconomyLeaders` همان
  payload را می‌گیرد و وقتی میزِ کلان خاموش است، از **همان دور** جایگزینِ
  واقعی می‌خواند (کلاسِ رمزارز، فیدِ سهام، جریانِ زنجیره، دو بازدهِ واقعیِ
  ۲ و ۱۰ ساله برای منحنی) و با برچسبِ «منبع جایگزین» اعلام می‌کند. اگر هیچ
  چیزی خوانده نشده باشد، همان «در این دور خوانده نشد.» می‌ماند.
- ۲۹ کلیدِ تازهٔ `insights.*` در هر **۱۲** زبان ترجمه شد. در
  `flowRankSub` عمداً از `{{rows}}` استفاده شد نه `{{count}}` — i18next
  متغیرِ `count` را به‌عنوان انتخاب‌گرِ جمع می‌خواند و سراغ
  `flowRankSub_one/_other` می‌رود.

## محدودیتِ صادقانهٔ همین تغییر

`node_modules` در این محیط نصب نیست و شبکهٔ bash بسته است، پس
`npm test`، `vitest` و `vite build` **اجرا نشده‌اند**. آنچه اجرا شده:
`node --check` روی همهٔ فایل‌های سرور، probe جدید (۷۷/۷۷)، و
`test/wiring.mjs` (۲۸۰۰ بررسی). فرمان‌هایی که باید روی دستگاهِ خودتان
سبز شوند:

```bash
npm ci
npm run test:capital-flows
node --input-type=module -e "import run from './test/wiring.mjs'; const r=run(); console.log('total',r.length,'failed',r.filter(x=>!x[1]).length)"
npm run build
```
