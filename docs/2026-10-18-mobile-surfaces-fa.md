# اصلاح رابط موبایل، تحلیل توکن و رادار — ۲۰۲۶/۱۰/۱۸

## سیگنال هوشمند
- پس‌زمینه با لبه‌های صریح و grid-area خودکار کل پنل را می‌پوشاند؛ قرار دادن صحنه داخل محدودهٔ محتوایی grid باعث باقی ماندن حاشیهٔ خالی می‌شد.
- اسلات متن دیگر عرض صفر ندارد؛ روی موبایل دو خط با ارتفاع ثابت دارد تا جملهٔ بلند هم خوانا بماند.
- متن چرخشی از لایهٔ ساده و انیمیشن opacity استفاده می‌کند، نه متن شفاف gradient-clip روی لایهٔ Framer Motion. چرخهٔ ۳۰ ثانیه‌ای حفظ شده است.
- در اندروید ویدیو اصلاً mount نمی‌شود؛ پس‌زمینهٔ سبک بدون turbulence و بدون انیمیشن ستاره‌ها نمایش داده می‌شود. سیاست‌های قبلی iOS، حالت کاهش حرکت و صرفه‌جویی داده حفظ شده‌اند.

## تحلیل سهام توکنیزه
- علت مهم خالی بودن نمودار: `/api/chart/:id` آرایهٔ `{t,p}` برمی‌گرداند، ولی تحلیل تنها `{prices:[[t,p]]}` را می‌خواند. اکنون هر دو قالب واقعی پشتیبانی می‌شوند؛ نقاط نامعتبر حذف و زمان‌ها مرتب و یکتا می‌شوند.
- نمای پیش‌فرض روز جاری (۲۴ ساعت) است؛ بازه‌های ۱۴ و ۹۰ روز نیز قابل انتخاب هستند. دادهٔ بازهٔ قبلی زیر عنوان بازهٔ جدید نمایش داده نمی‌شود.
- قیمت نقدی هنگام باز بودن پنل هر ۳۰ ثانیه و تاریخچه هر ۶۰ ثانیه درخواست می‌شود؛ این فید تیک‌به‌تیک نیست و در رابط توضیح داده شده است. در تب مخفی، polling مطابق hook مشترک متوقف می‌شود.
- برای توکن بدون تاریخچه نیز مشاهدات واقعی از پاسخ قیمت جمع‌آوری می‌شود؛ تا دومین مشاهده، تنها قیمت با توضیح انتظار نمایش داده می‌شود، نه نمودار ساختگی.
- تحلیل آماری تاریخی از نمونه‌های لحظه‌ای تولید نمی‌شود. خطای به‌روزرسانی قیمت صریحاً نمایش داده می‌شود.

## پیشنهادهای خرید/فروش و همتا‌به‌همتا
- کارت‌های مستقل برای Ramp Network، Swapzone و Guardarian با نشان‌های محلی متمایز (نه نشان تأیید رسمی)، دامنهٔ مقصد، شروط احراز/پوشش و اقدام اصلی با ارتفاع مناسب لمس.
- هیچ منطق صلاحیت کشور، KYC، رتبه‌بندی یا URL پرداخت تغییر نکرده است. هنگام باز شدن یک مقصد، کلیک هم‌زمان روی مقصد دیگر غیرفعال می‌شود.
- بنر همتا‌به‌همتا با پالت آبی یخی/بنفش، مسیر بصری و تب‌های یکپارچه بازطراحی شده است؛ کنترل با صفحه‌کلید و حالت کاهش حرکت حفظ شده‌اند.

## رادار سفارش خودکار
- بازوی رادار روی یک لایهٔ HTML مربعی با مرکز ثابت می‌چرخد؛ دیگر به bounding box نامتقارن یک گروه SVG و تفاوت transform-box مرورگرها وابسته نیست.
- ظاهر آمار و قاب نیز بهبود یافته است؛ آمار و منطق اجرای سفارش تغییر نکرده‌اند.

## اعتبارسنجی
- ساخت production: `npm run build`.
- ۸۰ تست UI در پنج فایل مربوط به بنر، تحلیل زنده، سفارش و سهام.
- ۳۳ تست دادهٔ نمودار و قیمت، شامل قالب واقعی پاسخ سرور و fallback.
- ۵۹ بررسی جریان کامل ویزارد خرید/فروش.
- probeهای تحلیل، خرید/فروش و همتا‌به‌همتا در processهای جدا اجرا می‌شوند؛ بعضی probeها تنظیمات محیط را در زمان import عوض می‌کنند و نباید در یک process پشت‌سرهم import شوند.
- تست واقعی Chromium: `npm run dev:web` سپس `npm run test:mobile-surfaces:browser`؛ در صورت نیاز `PUPPETEER_EXECUTABLE_PATH` را مشخص کنید.
- مرورگر با user-agent اندروید: عرض‌های ۳۲۰/۳۹۰/۱۲۸۰، فارسی/انگلیسی، تم روشن/تیره، تغییر عبارت، چرخش رادار، تب‌ها و کلیدهای جهت‌یابی، و کاهش حرکت بررسی شده‌اند.
- این شبیه‌سازی مرورگر است؛ تست فیزیکی گوشی اندروید یا Safari آیفون در این محیط انجام نشده است. وضعیت اتصال به فیدهای واقعی و استقرار production جداگانه بررسی می‌شود.
