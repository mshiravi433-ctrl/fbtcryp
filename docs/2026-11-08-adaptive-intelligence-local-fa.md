# اکوسیستم تطبیقی محلی ۳۲۵ — دامنه و راهنمای استفاده

## دامنه

این نسخه یک اکوسیستم محلی **محدود به کورتکس موجود و داده‌های بازار موجود در رابط** است؛ موتور علمی عمومی یا تضمین بهبود عملکرد و سودآوری نیست. پردازش با Worker و در صورت دسترسی، WebGPU برای بخشی از شبکهٔ اسپایکی، و در غیر این صورت CPU انجام می‌شود. آزمایش cloneها روی CPU اجرا می‌شود. GPU عمومی یا مستقل بودن همهٔ مراحل از CPU ادعا نمی‌شود.

## کنترل کاربر و شبکه

- پردازش به‌صورت پیش‌فرض متوقف است؛ کاربر باید از پنل کورتکس آن را فعال کند. انتخاب در تنظیمات محلی مرورگر باقی می‌ماند. تنظیمات قدیمی swarm خودکار به نسخهٔ جدید منتقل نمی‌شوند.
- اکوسیستم از تابع `syncWithGlobalSwarm` نیز هیچ درخواست یا آپلودی انجام نمی‌دهد. کل مسیر محاسبهٔ کورتکس مستقل از API سرور است. نمودارهای دیگر اپ ممکن است **جداگانه** دادهٔ بازار را از شبکه بگیرند و بارگذاری اولیهٔ اپ نیز شبکه لازم دارد.
- بعد از فعال‌کردن، اتاق تحلیل کندل‌های موجود خودش را به کورتکس می‌دهد. دکمهٔ آزمایش محلی از همان دادهٔ موجود (حداکثر ۲۵۶ کندل) استفاده می‌کند؛ حداقل ۱۶ کندل لازم است و خود دکمه فید جدیدی دریافت نمی‌کند.
- توقف، انتخاب خودکار/متعادل/کم‌مصرف و پاک‌کردن حافظهٔ محلی در پنل در دسترس‌اند. آزمایش صرفاً با فرمان کاربر اجرا می‌شود. اگر Worker وجود نداشته باشد مسیر CPU inline به‌کار می‌رود؛ اجرای این مسیر می‌تواند رابط را کند کند.

## محافظ‌ها و محدودیت‌ها

- محاسبه در شروع درخواست در پس‌زمینه یا حالت توقف رد می‌شود؛ حالت کم‌مصرف، باتری کم، دستگاه کم‌توان یا تأخیر بالا آزمایش cloneها را متوقف می‌کند. اطلاعات باتری و حافظه همیشه در دسترس نیستند و تأخیر **اندازه‌گیری دمای واقعی نیست**. کار شروع‌شده بین پیام‌ها در Worker صف‌بندی می‌شود؛ تغییر وضعیت بر درخواست بعدی اعمال می‌شود، نه تضمین توقف آنی محاسبهٔ جاری. محدودیت تعداد کندل، تعداد clone و timeout برای کاهش هزینه وجود دارد.
- معیار clone روی دادهٔ انتخاب آن است. در نبود اعتبارسنجی مستقل، clone برنده به صورت خودکار جایگزین نمی‌شود و رابط این محدودیت را نمایش می‌دهد. خود کورتکس همچنان می‌تواند مطابق سیاست منابع به صورت آنلاین تطبیق پیدا کند؛ این تضمین بهبود یا پیش‌بینی نیست.
- حافظهٔ اپیزودیک محلی محدود است و قابلیت حذف دارد؛ این یک حافظهٔ علمی جامع نیست. نبود تراکنش یا توصیهٔ سرمایه‌گذاری جزو مرز این قابلیت است.
- تست Node و jsdom جایگزین تست Web Worker، WebGPU و مصرف باتری روی مرورگر و سخت‌افزار واقعی نیستند. برای انتشار مطمئن، روی Chrome/Android/iOS و دستگاه‌های ضعیف باید پردازش، قطع شبکه پس از دریافت داده، عملکرد واقعی GPU، گرما و باتری بررسی شوند.
