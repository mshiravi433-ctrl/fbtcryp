# صفحهٔ «چه چیزی جدید است؟» — `/#/whats-new`

> یک صفحه، یک فایلِ تولیدشده، صفر فراخوانی سرور. این دفترچه می‌گوید چه چیزی
> ساخته شد، چرا این‌طور ساخته شد، و بعد از این برای انتشار یک تغییر چه باید کرد.

## ۱. مسئله

تنها سابقهٔ تغییرات، `CHANGELOG.md` در مخزن بود. کسی که از سایت استفاده می‌کند
نه مخزن را می‌شناسد و نه باید بشناسد؛ پس از دید او هر انتشار شبیه «هیچ
انتشار» بود — پوستهٔ سایت قبل و بعد یکی است. صفحه‌ای لازم بود که همان فایل را
**داخل محصول** نشان بدهد.

## ۲. چرا فایلِ بیلد و نه مسیر API

سه راه ممکن بود. این پروژه در ۱۰ نوامبر ۲۰۲۶ به‌خاطر `fluidCpuDuration`
(۱۰۳٪ از ۴ ساعت) مکث شد، پس معیار انتخاب «ارزان‌ترین برای CPU» است، نه
«ساده‌ترین برای نوشتن»:

| راه | هزینه | چرا نه |
| --- | --- | --- |
| `GET /api/whats-new` | یک فراخوانی + cold start برای هر بازدید | یک فهرست تاریخ نباید بتواند بودجهٔ CPU را بخورد |
| ایمپورت مارک‌داون در باندل | ~۱ مگابایت در چانک نزدیک به اولین رندر | پرداخت برای صفحه‌ای که بیشتر بازدیدکننده‌ها باز نمی‌کنند |
| **تولید JSON در زمان بیلد** ✅ | یک فایل ایستا روی CDN | صفر CPU، صفر فراخوانی، همیشه هم‌نسخهٔ همان کامیت |

## ۳. اجزا

| فایل | کار |
| --- | --- |
| `scripts/gen-whats-new.mjs` | `CHANGELOG.md` → `public/whats-new.json` (۸۰ موردِ تازه، ≈۹۴KB) |
| `src/pages/WhatsNew.jsx` | صفحه؛ چانکِ سطح مسیر، فقط هنگام باز شدن دانلود می‌شود |
| `src/styles/whats-new.css` | استایل از توکن‌های `src/index.css` (تم Noir و روشن هر دو) |
| `src/App.jsx` | `<Route path="/whats-new">` + نام مستعار `/changelog` |
| `src/components/MoreSheet.jsx` | ردیف «تغییرات» در گروه «بیشتر» (کلید `nav.whatsNew`) |
| `test/whats-new.test.mjs` | ۹ تست روی پارسر و خروجی |

داده در `public/whats-new.json` است و **در گیت نیست** (`.gitignore`): فایلی که
از CHANGELOG مشتق می‌شود اگر کامیت شود، هم از منبعش جدا می‌افتد و هم روی هر
یادداشتِ انتشار تعارض merge می‌سازد.

## ۴. کجا وصل شد — و یک تلهٔ واقعی

```jsonc
// package.json
"prebuild":   "node scripts/gen-whats-new.mjs && …",   // npm run build محلی
"predev":     "… && node scripts/gen-whats-new.mjs",  // npm run dev
"whats-new":  "node scripts/gen-whats-new.mjs",       // دستی
// داخل "build:full" هم اضافه شد  ← این مهم است
```

`vercel.json` دستور بیلد را `npm run build:full` صدا می‌زند. npm فقط
`prebuild:full` را خودکار اجرا می‌کند (که وجود ندارد)، نه `prebuild`. پس اگر
تولید فقط در `prebuild` بود، صفحه **محلی کار می‌کرد و در production ۴۰۴
می‌داد** — بدترین نوع اختلاف.

## ۵. چهار تصمیم که صفحه را صادق نگه می‌دارد

1. **ارقام فارسی.** سرفصل‌ها `# ۲۰۲۶-۱۱-۱۰` هستند؛ پارسر ارقام فارسی/عربی را
   به ASCII تبدیل می‌کند. بدون این، صفر مورد پارس می‌شد و صفحه «تغییری نیست»
   نشان می‌داد — که شبیه خرابیِ محصول است، نه خرابیِ پارسر.
2. **سرفصلِ بی‌تاریخ کارت نمی‌شود.** `# Changelog` و `# Unreleased — …`
   رد می‌شوند: تاریخ همان چیزی است که ادعا را قابل‌بررسی می‌کند.
3. **تاریخ نسبی وجود ندارد.** «۳ ساعت پیش» نه؛ فقط تاریخِ ثبت‌شده (و با
   `Intl.DateTimeFormat` در تقویم و ارقام خواننده).
4. **فیلترِ بازه بر مبنای داده.** «۷ روز» و «۳۰ روز» از جدیدترین موردِ فایل
   حساب می‌شود، نه از ساعتِ دستگاه؛ وگرنه هر کس ساعتش جلو باشد صفحهٔ خالی
   می‌بیند و فکر می‌کند خراب است.

## ۶. برای انتشار یک تغییر، از این به بعد

1. یک سرفصل بالای `CHANGELOG.md` با قالب `# ۲۰۲۶-۱۱-۱۰ — «تیتر»: توضیح` و
   دو-سه بولتِ واقعی زیرش.
2. اگر توضیح بلندتری داری، فایلِ `.md` بساز و در خطِ `جزئیات:` لینکش کن — همان
   لینک روی کارت ظاهر می‌شود («جزئیات کامل»).
3. `npm run whats-new` تا `public/whats-new.json` تازه شود (یا `npm run dev`
   که خودش می‌سازد). بعد `/#/whats-new` را باز کن.
4. اگر سرفصل بی‌تاریخ بنویسی، روی صفحه نمی‌آید. این خطاست که عمداً ساکت نیست:
   `npm run whats-new` تعداد مواردِ پارس‌شده را چاپ می‌کند.

## ۷. محدودیت‌ها (صادقانه)

- صفحه **۸۰ موردِ تازه** را نشان می‌دهد و تعداد قدیمی‌ترها را می‌نویسد؛ بقیه در
  `CHANGELOG.md` است. این سقف عمدی است تا صفحه روی موبایل سبک بماند.
- مارک‌داون کامل رندر نمی‌شود: بولت‌ها متنِ ساده‌اند و حداکثر ۳ بولت با ~۱۹۰
  کاراکتر در هر کارت. برای خواندن کل متن، «جزئیات کامل».
- فقط `fa` و `en` کپی دارند؛ ده زبان دیگر انگلیسی می‌بینند (عمداً، نه کلیدِ
  ترجمهٔ خام).
- صفحه هیچ‌جا نمی‌نویسد «نسخه» — پروژه شماره نسخه ندارد و ساختنش برای یک صفحه
  یعنی یک عددِ تازه که باید نگه‌داری شود.

## ۸. تست
