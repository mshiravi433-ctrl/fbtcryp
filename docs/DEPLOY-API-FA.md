# چرا هوش مصنوعی کار نمی‌کند و چطور درستش کنیم

## مشکل چیست

کلیدهایی که فرستادی درست هستند و کد هم درست است. مشکل جای دیگری است:

**هیچ سروری برای اپ وجود ندارد.**

هوش مصنوعی عمداً سمت سرور اجرا می‌شود، نه داخل اپ. دلیلش این است که اگر کلید
OpenRouter داخل فایل اپ باشد، هر کسی می‌تواند بازش کند و ببیندش — ربات‌ها این
کلیدها را ظرف چند ساعت پیدا می‌کنند و هزینه استفاده دیگران روی حساب تو می‌افتد.

پس اپ باید به یک سرور وصل شود که کلیدها آنجا هستند. آن سرور هنوز راه‌اندازی
نشده، برای همین وقتی در راهنما سوال می‌پرسی، هیچ اتفاقی نمی‌افتد.

```
اپ اندروید  →  /api/ai/faq  →  ❌ هیچ سروری وجود ندارد
```

بعد از راه‌اندازی:

```
اپ اندروید  →  https://your-app.vercel.app/api/ai/faq  →  ✅ سرور با کلیدها
```

## راه‌حل: رایگان روی Vercel (حدود ۱۰ دقیقه)

همه‌چیز از گوشی قابل انجام است.

### مرحله ۱ — ساخت حساب

برو به **vercel.com** → **Sign Up** → با حساب **GitHub** وارد شو.

### مرحله ۲ — وارد کردن پروژه

۱. روی **Add New** → **Project** بزن
۲. مخزن **fbtcryp** را پیدا کن → **Import**
۳. در قسمت Branch، برنچ `arena/019fa427-fbtcryp` را انتخاب کن
۴. تنظیمات build را دست نزن (فایل `vercel.json` خودش تنظیمشان می‌کند)
۵. هنوز **Deploy** نزن — اول مرحله ۳

### مرحله ۳ — گذاشتن کلیدها

در همان صفحه، بخش **Environment Variables** را باز کن و این دو را اضافه کن:

| Name | Value |
|---|---|
| `OPENROUTER_API_KEY` | `sk-or-v1-652e7d33...` (کلیدی که فرستادی) |
| `JINA_API_KEY` | `jina_28c81e94...` (کلیدی که فرستادی) |

اختیاری ولی مفید:

| Name | Value |
|---|---|
| `AI_MODEL` | `openai/gpt-4o-mini` (ارزان و سریع) |
| `COINGECKO_API_KEY` | اگر کلید CoinGecko داری |

> ⚠️ این‌ها را حتماً در **Environment Variables** بگذار، نه جای دیگر. و هرگز
> جلوی اسمشان `VITE_` نگذار — هر چیزی که با `VITE_` شروع شود داخل فایل اپ
> کپی می‌شود و برای همه قابل دیدن است.

### مرحله ۴ — Deploy

**Deploy** را بزن. حدود ۲ دقیقه طول می‌کشد.

بعد یک آدرس می‌گیری، چیزی شبیه:

```
https://fbtcryp.vercel.app
```

### مرحله ۵ — تست کن که سرور بالاست

این آدرس را در مرورگر باز کن (به‌جای اسم خودت):

```
https://fbtcryp.vercel.app/api/ai/status
```

باید ببینی:

```json
{"enabled":true,"news":true}
```

اگر `false` بود یعنی کلیدها درست ذخیره نشده‌اند — به Vercel برگرد و
Environment Variables را چک کن، بعد **Redeploy** بزن.

### مرحله ۶ — وصل کردن اپ به سرور

حالا باید به اپ بگوییم سرور کجاست.

۱. در گیت‌هاب برو به **Settings** → **Secrets and variables** → **Actions**
۲. تب **Variables** → **New repository variable**
۳. اضافه کن:

| Name | Value |
|---|---|
| `VITE_API_BASE` | `https://fbtcryp.vercel.app/api` |

(اسم دامنه خودت را بگذار، و `/api` را فراموش نکن)

۴. برو به تب **Actions** → **Build APK** → **Run workflow**

APK جدیدی که ساخته می‌شود به سرور وصل است و هوش مصنوعی کار می‌کند.

## هزینه

- **Vercel**: پلن رایگان برای این حجم کافی است
- **OpenRouter**: به ازای هر درخواست پول می‌گیرد. با مدل `gpt-4o-mini` هر
  تحلیل حدود یک دهم سنت است. پاسخ‌ها **روزانه کش می‌شوند**، یعنی اگر هزار
  نفر تحلیل بیت‌کوین را ببینند، فقط یک بار هزینه می‌دهی.
- **Jina**: پلن رایگان سقف مشخصی دارد که برای شروع کافی است.

توصیه می‌کنم در حساب OpenRouter یک **سقف هزینه ماهانه** بگذاری تا اگر ترافیک
ناگهانی زیاد شد، غافلگیر نشوی.

## امضای APK برای انتشار

نسخه فعلی **debug-signed** است. برای نصب مستقیم مشکلی ندارد، ولی برای
Google Play باید با کلید خودت امضا شود.

### ساخت کلید امضا

روی کامپیوتر (یا Termux روی اندروید) یک بار این را اجرا کن:

```bash
keytool -genkey -v -keystore fbt-release.keystore \
  -alias fbt -keyalg RSA -keysize 2048 -validity 10000
```

رمزی که می‌گذاری را جایی امن ذخیره کن.

> 🔴 این فایل را گم نکن. اگر گم شود، **دیگر هرگز نمی‌توانی برای همان اپ
> در Google Play به‌روزرسانی منتشر کنی** و باید اپ را از صفر با نام بسته
> جدید منتشر کنی. یک نسخه پشتیبان آفلاین نگه دار.

### اضافه کردن به گیت‌هاب

فایل را به base64 تبدیل کن:

```bash
base64 -w0 fbt-release.keystore
```

بعد در گیت‌هاب: **Settings** → **Secrets and variables** → **Actions** →
تب **Secrets** (نه Variables) → این چهار مورد را اضافه کن:

| Secret | مقدار |
|---|---|
| `ANDROID_KEYSTORE_BASE64` | خروجی دستور base64 بالا |
| `ANDROID_KEYSTORE_PASSWORD` | رمز keystore |
| `ANDROID_KEY_ALIAS` | `fbt` |
| `ANDROID_KEY_PASSWORD` | رمز کلید |

از این به بعد هر build خودکار **release امضاشده** تولید می‌کند. اگر این
Secretها نباشند، همان debug ساخته می‌شود و چیزی خراب نمی‌شود.
