# هر مقدار را از کجا بیاور و کجا بگذار

این سند فقط یک سؤال را جواب می‌دهد: **هر کلید را از کجا پیدا کنم و دقیقاً کجا بگذارم.**

همه‌اش با گوشی و مرورگر قابل انجام است. **به Termux نیاز نداری.**

---

## اول یک خبر خوب

کلیدهای VAPID را **قبلاً داری**. آن چیزی که در چت فرستادی با برچسب
«Push key pair» و «Private key»، یک جفت‌کلید VAPID کاملاً معتبر است — بررسی‌اش کردم:

- کلید عمومی: ۸۷ کاراکتر، که به ۶۵ بایت با بایت اول `0x04` باز می‌شود ✅ (دقیقاً فرمت درست)
- کلید خصوصی: ۴۳ کاراکتر ✅

یعنی لازم نیست چیزی بسازی. **فقط باید در فایربیس یکی نو بسازی** (چون این یکی در چت لو رفته)
و مقدارش را در ورسل بگذاری. هر دو نیمه در همان صفحهٔ فایربیس نشان داده می‌شوند.

## جدول خلاصه — قبل از شروع یک نگاه بینداز

| متغیر | از کجا می‌آید | کجا می‌رود |
|---|---|---|
| `VITE_VAPID_PUBLIC_KEY` | فایربیس ← Cloud Messaging | ورسل |
| `VAPID_PRIVATE_KEY` | همان صفحه، ستون بغلی | ورسل |
| `VAPID_SUBJECT` | ایمیل خودت | ورسل |
| `CRON_SECRET` | خودت می‌سازی (پایین توضیح دادم) | ورسل |
| `FIREBASE_PROJECT_ID` | `fbt-room-a46fc` | ورسل |
| `FIREBASE_CLIENT_EMAIL` | فایل JSON سرویس‌اکانت | ورسل |
| `FIREBASE_PRIVATE_KEY` | همان فایل JSON | ورسل |
| `ALCHEMY_API_KEY` | داشبورد Alchemy | ورسل |

**همه‌شان در ورسل می‌روند. هیچ‌کدام در گیت‌هاب نمی‌روند.**

## جایی که همهٔ این‌ها را می‌گذاری

این مسیر را حفظ کن، چون هشت بار می‌روی سراغش:

```
vercel.com  ←  پروژهٔ fbtcryp-kkxi  ←  Settings  ←  Environment Variables
```

برای هر متغیر:

1. روی **Add New** بزن
2. **Key** = اسم متغیر (دقیقاً، با حروف بزرگ، بدون فاصله)
3. **Value** = مقدار
4. **هر سه تیک** را بزن: Production ✅ Preview ✅ Development ✅
5. **Save**

> ⚠️ اگر تیک **Production** را نزنی، سایت اصلی آن متغیر را نمی‌بیند و
> همه‌چیز دقیقاً همان‌طور می‌ماند که بود.

## ۱) کلیدهای VAPID — از کنسول فایربیس

### پیدا کردن

**۱.** برو به `console.firebase.google.com`

**۲.** پروژهٔ **`fbt-room-a46fc`** را باز کن

**۳.** بالا سمت چپ، کنار «Project Overview»، روی **چرخ‌دنده ⚙️** بزن ← **Project settings**

**۴.** تب **Cloud Messaging** را باز کن

**۵.** اسکرول کن پایین تا بخش **Web Push certificates** (گاهی زیر عنوان «Web configuration»)

اینجا یک ردیف می‌بینی با دو ستون: **Key pair** و **Private key** — همان دو مقداری
که قبلاً فرستادی، از همین‌جا آمده بودند.

### چون لو رفته، یکی نو بساز

**۶.** روی **سه‌نقطهٔ ⋮** کنار ردیف موجود بزن ← **Delete**

**۷.** حالا روی **Generate key pair** بزن

یک جفت نو ساخته می‌شود. **این صفحه را نبند.**

### گذاشتن در ورسل

| Key در ورسل | مقدار |
|---|---|
| `VITE_VAPID_PUBLIC_KEY` | ستون **Key pair** (رشتهٔ بلند، ۸۷ کاراکتر، با `B` شروع می‌شود) |
| `VAPID_PRIVATE_KEY` | ستون **Private key** (کوتاه‌تر، ۴۳ کاراکتر) |
| `VAPID_SUBJECT` | `mailto:` + ایمیل خودت — مثلاً `mailto:you@gmail.com` |

> ⚠️ **به `VAPID_PRIVATE_KEY` هرگز پیشوند `VITE_` نده.**
> هر متغیری که با `VITE_` شروع شود، داخل فایل جاوااسکریپتی که همهٔ کاربران دانلود می‌کنند
> کامپایل می‌شود. یعنی با آن پیشوند، «راز» نیست — منتشر شده است.
>
> کلید **عمومی** عمداً `VITE_` دارد چون قرار است در مرورگر باشد. این درست است.

> 🔒 **در چت نفرست.** هرکس کلید خصوصی را داشته باشد می‌تواند به همهٔ کاربرانت
> نوتیفیکیشن بفرستد، با نام تو. اگر اشتباهی جایی فرستادی‌اش، برگرد به قدم ۶ و دوباره بساز.

## ۲) `CRON_SECRET` — این یکی را خودت می‌سازی

این فقط یک رمز است که جلوی `/api/cron/daily` را می‌گیرد. بدون آن، هرکس آدرس را پیدا کند
می‌تواند هر وقت خواست به همهٔ کاربرانت نوتیفیکیشن بفرستد.

**قالب خاصی ندارد.** فقط باید طولانی و تصادفی باشد. یکی از این دو راه:

- در مرورگر گوشی، یک تب باز کن و به `https://www.random.org/strings/` برو،
  یا هر رمزساز دیگری
- یا خودت ۳۰ کاراکتر بی‌ربط تایپ کن: حروف بزرگ و کوچک و عدد، بدون فاصله

مثال از **قالب** (این را کپی نکن، خودت یکی بساز):
`k7Qm2xR9vT4nB8wL5pZ3hJ6yD1sF0gA`

در ورسل: `CRON_SECRET` = همان رشته.

## ۳) فایربیس سرویس‌اکانت — برای نوتیفیکیشن اندروید

این بخش لازم است تا **نصب‌کنندگان APK** نوتیفیکیشن بگیرند.
مرورگر با VAPID کار می‌کند، اپ اندروید فقط با این.

### هشدار جدی

فایلی که قبلاً فرستادی (`private_key_id: dd3e2f8a...`) **دسترسی کامل ادمین**
به کل پروژهٔ فایربیس می‌دهد — نه فقط نوتیفیکیشن. با آن می‌شود کل دیتابیس را خواند یا پاک کرد.

**کلید سرویس‌اکانت را نمی‌شود «عوض کرد». فقط می‌شود حذف و یکی نو ساخت.**

### پیدا کردن

**۱.** برو به `console.cloud.google.com/iam-admin/serviceaccounts`

**۲.** بالای صفحه، پروژهٔ **`fbt-room-a46fc`** را انتخاب کن

**۳.** روی `firebase-adminsdk-fbsvc@fbt-room-a46fc.iam.gserviceaccount.com` بزن

**۴.** تب **KEYS**

**۵.** کلیدی که با `dd3e2f8a` شروع می‌شود را پیدا کن ← **🗑 Delete** ← تأیید

**۶.** حالا **ADD KEY** ← **Create new key** ← نوع **JSON** ← **CREATE**

یک فایل `.json` در Downloads گوشی‌ات دانلود می‌شود.

### باز کردن فایل

فایل را با یک ویرایشگر متن باز کن (اگر نداری، «Files» گوشی معمولاً می‌تواند،
یا اپ رایگان «Text Editor»). چیزی شبیه این می‌بینی:

```json
{
  "type": "service_account",
  "project_id": "fbt-room-a46fc",
  "private_key_id": "...",
  "private_key": "-----BEGIN PRIVATE KEY-----\nMIIEvQIBADAN...\n-----END PRIVATE KEY-----\n",
  "client_email": "firebase-adminsdk-fbsvc@fbt-room-a46fc.iam.gserviceaccount.com",
  ...
}
```

### گذاشتن در ورسل

| Key در ورسل | از کجای فایل |
|---|---|
| `FIREBASE_PROJECT_ID` | `fbt-room-a46fc` |
| `FIREBASE_CLIENT_EMAIL` | مقدار `client_email` |
| `FIREBASE_PRIVATE_KEY` | مقدار `private_key` |

**دربارهٔ `FIREBASE_PRIVATE_KEY` — اینجا بیشتر آدم‌ها اشتباه می‌کنند:**

- **کل** رشته را کپی کن، از `-----BEGIN PRIVATE KEY-----` تا `-----END PRIVATE KEY-----\n`
- **آن `\n`ها را دست نزن.** حذفشان نکن، به Enter تبدیلشان نکن. همان‌طور که هستند بمانند.
  سرور خودش تبدیلشان می‌کند (`server/fcm.js` خط ۵۰).
- گیومه‌های `"` ابتدا و انتها را **نگذار** — فقط محتوای داخلشان

این شایع‌ترین دلیل شکست FCM است، و خطایی که می‌دهد (`invalid_grant`) هیچ سرنخی
دربارهٔ علت واقعی نمی‌دهد.

## چطور بفهمی کار کرد

این آدرس را باز کن:

```
https://www.lawpoetics.ir/api/cron/status
```

**الان این را می‌دهد:**
```json
{"web":{"configured":false,"missing":["VITE_VAPID_PUBLIC_KEY","VAPID_PRIVATE_KEY"]},
 "fcm":{"configured":false},"cronSecretSet":false,"canSend":false}
```

**بعد از کار درست، باید این باشد:**
```json
{"web":{"configured":true,"subscribers":0,"missing":[]},
 "fcm":{"configured":true,"devices":0,"missing":[]},
 "cronSecretSet":true,"canSend":false}
```

سه تا `true` را نگاه کن. `subscribers` و `devices` هنوز صفرند و این **طبیعی است** —
یعنی هنوز هیچ دستگاهی نوتیفیکیشن را روشن نکرده. `canSend` هم تا آن موقع `false` می‌ماند.

**تست نهایی:** در اپ برو به تنظیمات ← نوتیفیکیشن‌ها ← روشن کن. بعد دوباره این آدرس را باز کن.
حالا باید `devices` برابر `1` باشد. آن لحظه یعنی کل زنجیره کار می‌کند.

---

## اگر هنوز `missing` نشان می‌دهد

خودِ همین آدرس به تو می‌گوید کدام متغیر جا مانده — اسمش در آرایهٔ `missing` هست.
معمولاً یکی از این سه:

1. **تیک Production را نزده‌ای** ← برگرد و متغیر را ویرایش کن
2. **ریدیپلوی نکرده‌ای** ← بخش ۵
3. **اسم متغیر غلط تایپ شده** ← باید مو به مو یکی باشد، مثلاً
   `VAPID_PRIVATE_KEY` نه `VAPID_PRIVATEKEY`

هیچ‌وقت مقدار کلیدها را نشان نمی‌دهد، فقط اسم آن‌هایی که نیستند — پس می‌توانی
با خیال راحت خروجی‌اش را برایم بفرستی.
