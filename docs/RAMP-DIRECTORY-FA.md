## ۱) این چیست و چه چیزی را حل می‌کند

قبل از این، مسیرِ بدون ثبت‌نامِ صفحهٔ خرید **فقط یک در داشت**: Ramp. اگر کاربر در
کشوری بود که Ramp سرویس نمی‌دهد (ایران و حدود ۱۳۰ کشور دیگر)، صفحه یا خالی می‌شد
یا به لینکی می‌رسید که درِ بسته‌ای را نشان می‌داد.

الان صفحه، بر اساس **کشورِ سفارش**، فهرستِ همهٔ درهایِ بدون قرارداد را می‌سازد:

- **درهای باز** — با این‌که هر کدام چه چیزی را از پیش پر می‌کنند؛
- **درهای بسته** — با نام و دلیل (و منبع، وقتی منبعی وجود دارد)؛
- **ریل‌های همتا‌به‌همتا** — که هیچ ارائه‌دهنده‌ای نمی‌تواند آن‌ها را ببندد، برای
  وقتی که هیچ درِ کارت‌محوری باز نیست.

```
مبلغ → کیف پول → دارایی/شبکه → بازبینی
                                  ↓
                  rampOptions({ country, side, … })
                                  ↓
        [درهای باز] + [درهای بسته با دلیل] + [همتا‌به‌همتا]
                                  ↓
              باز شدنِ صفحهٔ خودِ ارائه‌دهنده
                                  ↓
        گزارشِ روی زنجیره (WalletWatchReport) — تنها حقیقت
```

## ۲) سه قانونی که این ماژول نمی‌تواند بشکند

| # | قانون | چگونه قفل شده |
|---|---|---|
| ۱ | **پوششِ جعلی ممنوع** | هر ردیف یا فهرستِ کشوریِ منتشرشدهٔ خود ارائه‌دهنده را دارد (`mode: 'exclusion'` + منبع + تاریخ) یا صریحاً می‌گوید نمی‌داند (`mode: 'unknown'`). فهرستی از حافظه، وبلاگِ ثالث یا حدس ساخته نمی‌شود. |
| ۲ | **هیچ اعتبارنامه‌ای از ما نیست** | هر ردیف با صفحهٔ عمومیِ خودِ ارائه‌دهنده کار می‌کند. تنها مقادیری که اضافه می‌شوند `VITE_*` و **عمومی** هستند (شناسهٔ انتساب). بدون‌شان لینک درست است، فقط درآمدی ثبت نمی‌شود. |
| ۳ | **هیچ‌چیز دور زده نمی‌شود** | کشوری که ارائه‌دهنده حذف کرده، با دلیل و منبع گزارش می‌شود و از فهرستِ باز حذف می‌گردد. پنهان نمی‌شود، دور نمی‌خورد، و هیچ پیشنهادی برای VPN یا کشورِ دیگر داده نمی‌شود. |

و قانونِ قدیمیِ مخزن پابرجاست: **«پرداخت تأیید شد» ممنوع.** وب‌هوکی در کار نیست؛
تنها سیگنالِ صادق، همان گزارشِ روی زنجیره است.

## ۳) ردیف‌ها

| ردیف | دسترسی | از پیش پر می‌شود | پوشش | ملاحظه |
|---|---|---|---|---|
| **Ramp Network** | عمومی (صفحهٔ مصرف‌کنندهٔ خودِ Ramp) | دارایی + ارز + مبلغ + کیف پول | فهرستِ حذفِ منتشرشده (ترانویسی‌شده ۲۰۲۶/۱۰/۱۱) | تنها ردیفی که کشورها را تأیید می‌کند |
| **Mercuryo** | نیاز به `VITE_MERCURYO_WIDGET_ID` | ارز + مبلغ | نامشخص | پارامترهای مستند فقط؛ آدرس کیف پول پیش‌پر نمی‌شود چون آن پارامتر را تأیید نکرده‌ایم |
| **Swapzone** | عمومی | دارایی + ارز در **مسیر** (`/buy/usd/usdt`) | نامشخص | مسیرها واقعاً بررسی شدند |
| **Guardarian** | عمومی | هیچ (صفحهٔ ماشین‌حسابِ خودشان) | نامشخص | ۱۷۰+ کشور در سایتشان، اما فهرستی برای ترانویسی ندارند |
| **P2P**: Hodl Hodl (داخل اپ، `/p2p`)، Bisq، RoboSats، Peach | عمومی | — | همه‌جا | بدون احراز هویت، با اسکرو، عمدتاً بیت‌کوین |

**چرا MoonPay / Transak / Coinbase / Stripe اینجا نیستند؟** چون ویجتشان بدون
قراردادِ شریک و KYBِ شخصیت حقوقیِ ما اصلاً بالا نمی‌آید («Integration issue
detected»). لینک دادن به آن‌ها یعنی همان تپِ مُرده‌ای که این دایرکتوری برای حذفش
ساخته شده. جای آن‌ها `server/buySell.js` است که از قبل رجیستریِ چندارائه‌دهنده‌ای
دارد.

## ۴) خروجیِ ماژول

```js
rampOptions({ country: 'IR', side: 'BUY', asset: 'USDT', … })
// → {
//   country: 'IR', countryKnown: true, side: 'BUY',
//   options:     [ Swapzone, Guardarian ],          // درهای باز
//   unavailable: [ { id:'ramp', reason:'COUNTRY_EXCLUDED', source:'https://support.rampnetwork.com/…' } ],
//   p2p:         [ Hodl Hodl (داخل اپ), Bisq, RoboSats, Peach ],
//   coverageVerified: false,                        // هیچ ردیفی کشور را تأیید نکرد
//   recommended: 'swapzone'
// }
```

- `tier`: `full` → همه‌چیز پر شده · `partial` → بعضی · `page` → انتخاب در سایت مقصد.
  رتبه‌بندی فقط درباره‌ی **مقدار تایپِ باقی‌مانده** است، نه اینکه کدام ارائه‌دهنده بهتر یا ارزان‌تر است (نرخِ زنده‌ی هیچ‌کدام را اینجا نمی‌بینیم).
- `coverageVerified: false` ⇒ UI جمله‌ی صریحی نشان می‌دهد: «هیچ‌کدام فهرست کشوری منتشر نکرده‌اند؛ ممکن است در صفحهٔ خودشان بگویند کشور شما را سرویس نمی‌دهند.»

## ۵) تست‌ها

`npm test` → بخش **RAMP DIRECTORY** در `test/units.mjs` (۱۹ مورد):
منبع‌داشتنِ هر ادعای پوشش · فقط یک ردیفِ دارای فهرست · ISO-3166 بودنِ فهرست ·
ماندنِ هر URL رویorigin خودش · `NOT_CONFIGURED` برای Mercuryoِ بی‌شناسه ·
حذف شدنِ Ramp برای ایران با دلیل و منبع · همیشه برگشتنِ ریل‌های P2P ·
عدمِ ادعا برای کشورِ نامشخص · مسیرهای Swapzone · نرسیدنِ رشته‌ی مخرب به URL ·
و دروازه‌ی دوحرفیِ کشور.

`npm run test:buy-sell-wizard` (۵۶/۵۶): پنل را مثل کاربر می‌راند و تأیید می‌کند
که گامِ بازبینی **فهرستِ درها** را نشان می‌دهد، هر در دکمه و توضیحِ خودش را دارد،
درهای بسته با دلیل نمایش داده می‌شوند، ریلِ داخلی داخل اپ می‌ماند و ریلِ خارجی با
https باز می‌شود.

## ۶) افزودن یک ارائه‌دهنده (چک‌لیست)

۱. صفحهٔ عمومی‌اش را **خودت باز کن** و مطمئن شو بدون هیچ کلیدی بالا می‌آید.
۲. پارامترهای مستند را از داکسِ خودش بخوان — فقط همان‌ها را بفرست.
۳. اگر فهرستِ کشوریِ منتشرشده دارد: ترانویسی کن + لینکِ منبع + تاریخ. ندارد: `mode: 'unknown'`.
۴. ردیف را به `RAMP_DIRECTORY` اضافه کن و یک `BUILDERS[id]` بنویس.
۵. تست اضافه کن: origin، عدمِ ادعای پوشش، و اینکه URL فقط پارامترهای مجاز را دارد.

**هیچ‌وقت** برای پر کردنِ فهرست، از حافظه یا مقایسه‌ی وبلاگی استفاده نکن — این
دقیقاً همان خطایی است که قانونِ شماره‌ی ۱ جلویش را می‌گیرد.

## ۷) محدودیت‌های صادقانه

- **فروش (off-ramp) هنوز لبه است.** بیشترِ این ردیف‌ها خرید را بهتر از فروش پوشش می‌دهند؛
  فروشِ واقعی و رهگیری‌شده نیازمندِ مسیرِ قراردادی (`RAMP_ENABLED_FLOWS=ONRAMP,OFFRAMP`
  یا سناریو ۲).
- **درآمد فعلاً کم است.** هیچ کارمزدِ شریکی‌ای روی این ریل تنظیم نشده؛ شناسه‌های
  انتساب فقط وقتی تنظیم شوند درآمد می‌سازند.
- **وابستگی به صفحه‌ی ثالث.** مثل همان بلایی که سرِ `buy.ramp.network` آمد: اگر
  ارائه‌دهنده صفحه‌اش را عوض کند، لینک می‌شکند. همین‌طور که برای Ramp دارید،
  بازبینیِ دوره‌ای لازم است.
- **ریل‌های P2P کندتر و عمدتاً بیت‌کوین هستند**؛ مکمل‌اند، نه جایگزین.
