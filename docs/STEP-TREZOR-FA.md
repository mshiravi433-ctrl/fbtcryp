## قدم ۶ — بعد از تأیید: لینک را بردارید

وارد داشبورد شوید:

🔗 **https://affiliate.trezor.io/**

دنبال بخش **Links** یا **Creatives** بگردید. لینک اختصاصی‌تان چیزی شبیه
این است:

```
https://trezor.io/?offer_id=12&aff_id=123456
```

### ⚠️ کل لینک را کپی کنید، نه فقط عدد

کد من طوری نوشته شده که **هر دو حالت** را قبول کند، ولی **لینک کامل
بهتر است**:

- اگر **لینک کامل** بگذارید (شروع با `https://`) → عیناً همان استفاده
  می‌شود
- اگر فقط **عدد** بگذارید → کد خودش `?offer_id=<عدد>` می‌سازد

چرا لینک کامل بهتر است: بعضی وقت‌ها لینک ردیابی چند پارامتر دارد که
ترتیبشان مهم است. اگر من از روی تکه‌ها دوباره بسازمش، ممکن است ردیابی
**بی‌صدا خراب شود** — یعنی لینک کار کند، کاربر خرید کند، ولی به اسم شما
ثبت نشود. آن بدترین حالت است چون شبیه موفقیت به نظر می‌رسد.

## قدم ۷ — در Vercel قرار دهید

🔗 **https://vercel.com/dashboard**

۱. پروژهٔ **`fbtcryp-kkxi`** را باز کنید
۲. بالا → **Settings**
۳. منوی چپ → **Environment Variables**
۴. اضافه کنید:

| | |
|---|---|
| **Key** | `VITE_AFFILIATE_TREZOR` |
| **Value** | لینک کاملی که کپی کردید |
| **Environments** | ✅ Production ✅ Preview ✅ Development |

۵. **Save**

### 🚨 قدم ۸ که خیلی‌ها فراموش می‌کنند: Redeploy

**فقط Save کافی نیست.** هیچ اتفاقی نمی‌افتد.

۱. بالای صفحه → تب **Deployments**
۲. روی آخرین دیپلوی → **⋯** (سه نقطه) → **Redeploy**
۳. اگر پرسید، **Use existing Build Cache را تیک نزنید**
۴. حدود دو دقیقه صبر کنید تا سبز شود

**چرا لازم است:** متغیرهایی که با `VITE_` شروع می‌شوند موقع **ساختن**
برنامه داخل کد پخته می‌شوند، نه موقع اجرا. یعنی مقدارشان در همان فایل
جاوااسکریپتی که قبلاً ساخته شده نوشته می‌شود. تا دوباره ساخته نشود،
نسخهٔ قدیمی سرو می‌شود.

## قدم ۹ — تست کنید که واقعاً کار می‌کند

۱. به **https://fbtswap.ir** بروید
۲. پایین صفحه → **کیف پول**
۳. تب **واقعی** را بزنید (نه آزمایشی)

   دسترسی ندارد»**

### چه چیزی باید ببینید

زیر ردیف **Trezor** باید یک خط ریز اضافه شده باشد:

> «اگر از این لینک بخری، ۱۵٪ از مبلغ فروش را Trezor به ما می‌دهد. برای
> تو هیچ هزینهٔ اضافه‌ای ندارد...»

**اگر آن جمله را می‌بینید → کار کرد.** ✅

**اگر نمی‌بینید:**
- کارت هست ولی جمله نیست → متغیر نرسیده. Redeploy را دوباره چک کنید.
- اصلاً کارت نیست → مطمئن شوید تب **واقعی** هستید، نه **آزمایشی**.
  کارت عمداً فقط در تب واقعی نشان داده می‌شود — پیشنهاد یک دستگاه ۸۰
  دلاری برای محافظت از اعتبار مجازی بی‌معنی است.
