# ارتقای درک، آموزش و ارزیابی ریسک در چت

- تحلیلگران و جمع‌بندی‌کننده در درخواست‌های مرتبط، دستور مشترک برای پاسخ به نیاز واقعی کاربر، توجه اجتماعی، ریسک، آموزش و تفکیک سیگنال از دستور معامله دریافت می‌کنند. این مسیر اجازهٔ امضا یا اجرای معامله نمی‌دهد.
- خوانش احساس و موقعیت، چارچوب بازار و نگاه آموزشی در حالت متعادل هم برای درخواست‌های مربوط فعال است. در حالت عمیق دستورهای گفت‌وگو، آموزش و بازار به تحلیلگران اولیه نیز می‌رسند، نه فقط به جمع‌بندی‌کننده.
- در تصمیم‌های معاملاتی، دادهٔ خالی و توافق مدل‌ها به‌تنهایی شواهد محسوب نمی‌شوند. اگر پاسخ نهایی روی شواهد ناکافی همچنان دستور جهت‌دار بدون شرط بدهد، با توضیح احتیاطی جایگزین می‌شود. این بررسی متنی محدود است و تضمین کامل ایمنی یا کیفیت پاسخ نیست.
- دادهٔ بازار کش‌شدهٔ کهنه دیگر به نام زنده معرفی نمی‌شود. مقادیر خالی صفر تلقی نمی‌شوند و بازهٔ سه‌ماهه ۹۰ روز شناسایی می‌شود. دادهٔ موجود یک دارایی هنگام ترکیب با قیمت تنها از بین نمی‌رود.
- در اتاق فرصت، ریسک گزارش‌نشده به‌عنوان ریسک پایین و نمرهٔ ساختگی قرارداد/طرف مقابل ثبت نمی‌شود؛ پوشش ناکافی برای برچسب کم‌ریسک کافی نیست. دسته‌بندی زیان ناپایدار نیز عدد افت سرمایه فرضی تولید نمی‌کند.

## بررسی

`npm run test:ai-intelligence`، `npm run test:opportunities` و `node --test test/intent-ai/ai-expertise-upgrade.test.mjs` از داده‌ها و مدل‌های شبیه‌سازی‌شده استفاده می‌کنند؛ عملکرد مدل‌های خارجی و دادهٔ زنده به وضعیت سرویس‌ها و کلیدهای محیط استقرار وابسته است. این سیستم پیش‌بینی سود را تضمین نمی‌کند.
