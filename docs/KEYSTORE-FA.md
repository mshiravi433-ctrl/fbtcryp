# ساخت کلید امضا با موبایل — گام به گام

کلید امضا تنها چیزی است که بین اپ فعلی و انتشار در Google Play مانده.
با گوشی، حدود ۱۰ دقیقه.

---

## قبل از شروع: چرا این کلید انقدر مهم است

گوگل لیست اپ تو را **برای همیشه** به این کلید گره می‌زند.

- اگر گمش کنی، **نمی‌توانی اپ خودت را آپدیت کنی** — نه با کلید جدید، نه با
  تماس با گوگل. باید لیست جدید با نام پکیج جدید بسازی و همه کاربران قبلی
  یتیم می‌شوند.
- اگر کسی به آن دسترسی پیدا کند، می‌تواند آپدیت جعلی برای کاربران تو بفرستد.

دقیقاً مثل عبارت بازیابی کیف پول با آن رفتار کن.

**به همین دلیل من نمی‌سازمش.** اگر من بسازم، من کلید هویت اپ تو را دارم.
این مرزی است که حتی برای راحتی هم نباید رد شود.

---

## گام ۱ — نصب Termux

⚠️ **از F-Droid نصب کن، نه از Google Play.** نسخه Play Store سال‌هاست
به‌روزرسانی نشده و `pkg install` در آن خراب است.

۱. برو به **<https://f-droid.org/packages/com.termux/>**
۲. روی **Download APK** بزن و نصب کن
۳. Termux را باز کن

---

## گام ۲ — نصب Java

در Termux تایپ کن (یا کپی/پیست کن):

```bash
pkg update -y && pkg install openjdk-17 -y
```

حدود ۲ تا ۵ دقیقه طول می‌کشد. اگر پرسید ادامه بدهد، `y` بزن.

بررسی کن نصب شده:

```bash
keytool -help
```

اگر متن راهنما نشان داد، آماده‌ای.

---

## گام ۳ — ساخت کلید

### راه ساده (توصیه‌شده): با اسکریپت آماده

```bash
cd ~ && curl -fsSL -o mk.sh \
  https://raw.githubusercontent.com/mshiravi433-ctrl/fbtcryp/arena/019fa8cd-fbtcryp/ci/make-keystore.sh \
  && bash mk.sh
```

اسکریپت:
- رمز را دو بار می‌پرسد (زیر ۸ کاراکتر را قبول نمی‌کند)
- اگر از قبل کلیدی داشته باشی، **بدون تایید صریح آن را بازنویسی نمی‌کند**
- کلید را می‌سازد، خروجی base64 را در یک فایل می‌نویسد
- اثر انگشت SHA-1 را نشان می‌دهد
- دقیقاً می‌گوید چهار Secret را کجا بگذاری

### راه دستی (اگر ترجیح می‌دهی خودت ببینی چه اتفاقی می‌افتد)

```bash
mkdir -p ~/fbt-keystore && cd ~/fbt-keystore

keytool -genkeypair -v \
  -keystore fbt-release.keystore \
  -alias fbt \
  -keyalg RSA -keysize 2048 -validity 10950 \
  -storetype PKCS12 \
  -dname "CN=FBT Swap, OU=Mobile, O=Fanous Bazaar Pishgam, L=Isfahan, ST=Isfahan, C=IR"
```

دو بار رمز می‌پرسد (store و key). **همان رمز را برای هر دو بزن** — نگه داشتن
دو رمز متفاوت فقط یک راه اضافه برای اشتباه کردن است و امنیت بیشتری نمی‌دهد،
چون هر کسی رمز store را داشته باشد به فایل هم دسترسی دارد.

بعد خروجی base64 را بگیر:

```bash
base64 -w 0 fbt-release.keystore > keystore-base64.txt
cat keystore-base64.txt
```

یک رشته بلند چاپ می‌شود. **کل آن** را کپی کن (در Termux با نگه داشتن انگشت
روی صفحه و انتخاب).

---

## گام ۴ — پشتیبان‌گیری (این را رد نکن)

**همین حالا، قبل از هر کار دیگر.**

فایل را به پوشه دانلود گوشی کپی کن تا از Termux بیرون بیاید:

```bash
termux-setup-storage
cp ~/fbt-keystore/fbt-release.keystore ~/storage/downloads/
```

(بار اول اجازه دسترسی به حافظه می‌خواهد — قبول کن.)

حالا فایل در پوشه Downloads است. **حداقل دو جای جدا** نگهش دار:

- ✅ گوگل درایو یا آی‌کلاد شخصی
- ✅ یک فلش یا کارت حافظه
- ✅ ایمیل به خودت (فایل رمزدار است، ولی رمز را جدا نگه دار)
- ❌ **نه** داخل مخزن گیت — `.gitignore` جلویش را می‌گیرد ولی امتحانش نکن

**رمز را روی کاغذ بنویس.** رمز گم‌شده = کلید گم‌شده.

---

## گام ۵ — چهار Secret در گیت‌هاب

با مرورگر گوشی برو به:

**<https://github.com/mshiravi433-ctrl/fbtcryp/settings/secrets/actions>**

روی **New repository secret** بزن، چهار بار:

| # | Name | Value |
|---|---|---|
| ۱ | `ANDROID_KEYSTORE_BASE64` | کل محتوای `keystore-base64.txt` |
| ۲ | `ANDROID_KEYSTORE_PASSWORD` | رمزی که انتخاب کردی |
| ۳ | `ANDROID_KEY_ALIAS` | `fbt` |
| ۴ | `ANDROID_KEY_PASSWORD` | همان رمز |

⚠️ موقع پیست کردن base64 مطمئن شو **فاصله یا خط جدید اضافه** نیفتاده باشد.
اسکریپت آن را در یک خط می‌نویسد؛ اگر دستی گرفتی، دقت کن کامل باشد.

---

## گام ۶ — دو Variable

همان صفحه، تب **Variables** (نه Secrets):

| Name | Value |
|---|---|
| `VITE_API_BASE` | `https://<اپ-ورسل-تو>.vercel.app/api` |
| `APP_VERSION_CODE` | `1` |

`VITE_API_BASE` مهم است: اپ اندروید صفحاتش را از `https://localhost` سرو
می‌کند، پس مسیر نسبی `/api` به هیچ‌جا نمی‌رسد و اخبار و رتبه‌بندی کار
نمی‌کنند. قیمت‌ها همچنان کار می‌کنند چون به منابع عمومی fallback دارند.

برای هر انتشار بعدی `APP_VERSION_CODE` را **یکی زیاد کن** — گوگل آپلودی که
شماره‌اش از قبلی بالاتر نباشد را رد می‌کند.

---

## گام ۶.۵ — یک ویرایش لازم در فایل workflow ⚠️

**این را رد نکن، وگرنه Secretها بی‌اثر می‌مانند.**

گیت‌هاب Secretها را به‌طور خودکار در اختیار اسکریپت نمی‌گذارد — فقط وقتی در
بلوک `env:` صریحاً پاس داده شوند به اسکریپت می‌رسند. فایل فعلی این کار را
نمی‌کند، پس حتی با هر چهار Secret درست، بیلد **بی‌سروصدا** نسخه دیباگ می‌سازد
و به نظر می‌رسد کلید کار نکرده.

من نمی‌توانم این فایل را برایت ویرایش کنم — گیت‌هاب به توکن اپلیکیشن‌ها اجازه
نوشتن در `.github/workflows/` نمی‌دهد (امتحان کردم و رد شد). این یک ویرایش
یک‌باره است:

۱. برو به:
   **<https://github.com/mshiravi433-ctrl/fbtcryp/edit/arena/019fa8cd-fbtcryp/.github/workflows/build-apk.yml>**

۲. **کل محتوا** را پاک کن

۳. محتوای فایل `ci/WORKFLOW-FIXED.yml` را جایگزین کن. برای کپی راحت‌تر، نسخه
   خام را باز کن:
   **<https://raw.githubusercontent.com/mshiravi433-ctrl/fbtcryp/arena/019fa8cd-fbtcryp/ci/WORKFLOW-FIXED.yml>**

۴. **Commit changes**

بیلد بلافاصله شروع می‌شود.

## گام ۷ — بیلد

**<https://github.com/mshiravi433-ctrl/fbtcryp/actions>**

→ **Build APK** → **Run workflow** → دکمه سبز

حدود ۳ دقیقه. بعد در بخش **Artifacts**:

| فایل | کاربرد |
|---|---|
| `app-release.aab` | **← این را در Google Play آپلود کن** |
| `app-release.apk` | نصب مستقیم، کافه‌بازار، مایکت |

---

## چطور مطمئن شوم درست امضا شده؟

در لاگ بیلد، بعد از ساخت، اثر انگشت چاپ می‌شود. باید با SHA-1 که گام ۳ دیدی
یکی باشد.

اگر در لاگ نوشته بود `no keystore supplied — building debug APK`، یعنی
Secretها درست ثبت نشده‌اند — املای نام‌ها را چک کن.

---

## مشکلات رایج

| مشکل | علت و راه‌حل |
|---|---|
| `keytool: command not found` | Java نصب نشده. `pkg install openjdk-17 -y` |
| `pkg: command not found` | Termux را از Play Store نصب کرده‌ای. حذفش کن و از F-Droid بگیر |
| `Permission denied` موقع کپی | `termux-setup-storage` را اجرا نکرده‌ای |
| بیلد می‌گوید debug | نام Secretها را دقیق چک کن (حساس به حروف بزرگ/کوچک) |
| `keystore was tampered with` | رمز اشتباه است |
| base64 خیلی کوتاه به نظر می‌رسد | احتمالاً کامل کپی نشده — دوباره از فایل بگیر |

## خلاصه

```
F-Droid → Termux → pkg install openjdk-17 -y
                 → bash mk.sh   (رمز را دو بار بزن)
                 → پشتیبان در دو جا  ← مهم‌ترین گام
                 → ۴ Secret + ۲ Variable در گیت‌هاب
                 → ویرایش یک‌باره workflow (گام ۶.۵)
                 → Actions → Run workflow
                 → app-release.aab را بردار
```

اگر جایی گیر کردی، بگو کدام گام و چه پیامی دیدی.
