# API‌ها و سرویس‌های خارجی — چه چیزی لازم است و چه چیزی نیست

این سند پاسخ مستقیم این سوال است: «اگر به API نیاز داری بگو».

خلاصه: **برای اینکه اپ کار کند، هیچ کلیدی لازم نیست.** همه‌چیز با منابع
عمومی و بدون کلید کار می‌کند. کلیدها فقط سه چیز می‌دهند: سقف درخواست بالاتر،
هوش مصنوعی واقعی، و پوش نوتیفیکیشن سمت سرور. پایین دقیقاً مشخص شده کدام
قابلیت بدون کلید در چه حالتی است.

---

## ۱. کار می‌کند، بدون هیچ کلیدی

| قابلیت | منبع | وضعیت بدون کلید |
|---|---|---|
| قیمت‌ها و بازار | CoinGecko عمومی + CoinLore | کار می‌کند، محدودیت نرخ دارد |
| نمودارها | CoinGecko عمومی | کار می‌کند |
| جستجوی کل ارزها | CoinGecko `/search` | کار می‌کند |
| **فهرست توکن‌های سواپ** | tokenlists عمومی (PancakeSwap، Uniswap، CoinGecko) | کار می‌کند — هزاران توکن |
| **قیمت‌گیری و اجرای سواپ** | KyberSwap Aggregator | کار می‌کند، کلید نمی‌خواهد |
| موجودی‌ها | RPC عمومی هر شبکه | کار می‌کند |
| **اخبار** | RSS عمومی (Cointelegraph، CoinDesk، Decrypt، The Block…) | کار می‌کند |
| **راهنمای هوشمند** | پایگاه دانش داخلی اپ | کار می‌کند |
| **تحلیل هوش مصنوعی (سیگنال‌ها)** | اندیکاتورهای محلی + راوی داخلی | کار می‌کند — بدون هیچ کلیدی |
| صدا و لرزش معامله | Web Audio + Vibration API | کار می‌کند |
| اعلان روزانه | زمان‌بندی محلی روی دستگاه | کار می‌کند |

نکته مهم درباره سواپ: کارمزد ۰.۵٪ از طریق روتر ممیزی‌شده KyberSwap و در همان
تراکنش کاربر برداشته می‌شود. **هیچ قراردادی لازم نیست دیپلوی کنی و هیچ گسی
نمی‌پردازی.** فقط آدرس دریافت را تنظیم کن (که پیش‌فرض روی آدرس‌های خودت است).

## ۲. اختیاری — اگر می‌خواهی بهتر شود

### CoinGecko (رایگان)

بدون کلید محدودیت نرخ سخت‌گیرانه است و در ساعات شلوغ ممکن است داده دیر بیاید.
کلید Demo رایگان است و محدودیت را چند برابر می‌کند.

۱. برو به <https://www.coingecko.com/en/api/pricing> و پلن Demo (رایگان) بگیر
۲. در متغیرهای محیطی سرور بگذار:

```
COINGECKO_API_KEY=CG-xxxxxxxxxxxx
COINGECKO_PLAN=demo
```

**این کلید فقط سمت سرور است.** هرگز آن را در متغیری با پیشوند `VITE_` نگذار —
هر چیزی با آن پیشوند داخل فایل جاوااسکریپت اپ کامپایل می‌شود و همه می‌بینندش.

### Gemini یا OpenRouter (اختیاری — برای متن باز)

**مهم: بدون این هم تحلیل کار می‌کند.**

آنچه در صفحه سیگنال‌ها محاسبه می‌شود — RSI، MACD، بولینگر، میانگین‌های متحرک،
مومنتوم و نوسان محقق‌شده — همه روی خود دستگاه و از تاریخچه واقعی قیمت به دست
می‌آید. مدل زبانی هیچ‌وقت این اعداد را نمی‌ساخت؛ فقط دورشان جمله می‌نوشت.

حالا `src/lib/localOutlook.js` همان جمله‌ها را به‌صورت قطعی از همان اعداد و به
زبان کاربر می‌نویسد. مزیت جانبی‌اش این است که امن‌تر هم هست: یک مدل ممکن است
گاهی سطح قیمتی یا خبری از خودش دربیاورد، این نمی‌تواند — هر جمله از عددی می‌آید
که واقعاً محاسبه شده. در رابط کاربری هم صریح نوشته می‌شود «تحلیل اندیکاتورها»
نه «هوش مصنوعی»، تا کسی گمان نکند مدلی جواب داده.

جایی که مدل واقعاً بهتر است: سوال‌های باز و اتصال به اخبار. پس اگر کلید بگذاری،
مدل اولویت دارد و راوی محلی فقط پشتیبان می‌شود.

### عیب‌یابی: چرا هوش مصنوعی سمت سرور کار نمی‌کند

یک اندپوینت تشخیص ساختم که **واقعاً** به سرویس زنگ می‌زند و می‌گوید چه چیزی
خراب است — به‌جای اینکه فقط بگوید «در دسترس نیست»:

```
https://<اپ-تو>.vercel.app/api/ai/diagnose
```

بدون توکن فقط می‌گوید کدام کلیدها موجودند. با توکن، تست زنده انجام می‌دهد:

```
curl https://<اپ-تو>.vercel.app/api/ai/diagnose \
  -H "Authorization: Bearer $CRON_SECRET"
```

خروجی دقیقاً یکی از این‌هاست و راه‌حلش را هم می‌نویسد:

| reason | یعنی چه | راه‌حل |
|---|---|---|
| `NO_KEY` | هیچ کلیدی تنظیم نشده | `GEMINI_API_KEY` را در Vercel بگذار (نه با پیشوند `VITE_`) |
| `KEY_INVALID` | کلید غلط یا باطل شده | کلید جدید بساز |
| `KEY_RESTRICTED` | کلید هست ولی اجازه ندارد | در Google Cloud، Generative Language API را فعال کن. **اگر کلید را به اپ اندروید محدود کرده‌ای، از سرور کار نمی‌کند** |
| `MODEL_NOT_FOUND` | نام مدل اشتباه است | `GEMINI_MODEL=gemini-2.0-flash` |
| `QUOTA` | سهمیه تمام شده | صبر کن یا billing فعال کن |
| `NETWORK` | سرور به گوگل نمی‌رسد | **گوگل بعضی مناطق را مسدود می‌کند — منطقه دیپلوی Vercel را عوض کن** |
| `TIMEOUT` | جواب دیر آمد | مدل کوچک‌تر |

`NETWORK` و `KEY_RESTRICTED` شایع‌ترین‌اند. اولی معمولاً یعنی منطقه دیپلوی
مشکل دارد؛ دومی یعنی کلید را برای اندروید محدود کرده‌ای و حالا سرور با همان
کلید صدا می‌زند.

همین اطلاعات در خود اپ هم هست: **راهنما → از هوش مصنوعی بپرس → «چرا سمت سرور
کار نمی‌کند؟»**

### WalletConnect (رایگان)

برای اتصال کیف پول موبایلی از داخل تلگرام لازم است.

۱. <https://cloud.reown.com> → پروژه جدید
۲. `VITE_WALLETCONNECT_PROJECT_ID=...`

این یکی *عمداً* عمومی است — شناسه پروژه است نه رمز.

### Vercel Blob (برای رتبه‌بندی پایدار و کش هوش مصنوعی)

**این مهم‌ترین موردی است که برای انتشار واقعی لازم داری.**

توابع سرورلس Vercel بی‌حالت‌اند: هر بار که تابع سرد شود، حافظه‌اش خالی است.
بدون Blob، جدول رتبه‌بندی و اشتراک‌های پوش با هر کولد استارت پاک می‌شوند —
اپ خودش این را تشخیص می‌دهد و در صفحه رتبه‌بندی صریح می‌نویسد که رتبه محلی است.

۱. در داشبورد Vercel → Storage → Create → Blob
۲. توکن به‌صورت خودکار به‌عنوان `BLOB_READ_WRITE_TOKEN` اضافه می‌شود

## ۳. پوش نوتیفیکیشن — تنها موردی که واقعاً کلید می‌خواهد

### وضعیت بدون کلید: محلی، و اپ صریحاً همین را می‌گوید

بدون کلید VAPID، اعلان روزانه فقط **وقتی اپ را باز می‌کنی** نمایش داده می‌شود.

بگذار روشن باشد چرا این محدودیت جدی است: زمان‌بند محلی داخل خود اپ اجرا می‌شود،
پس تنها کسی که پیام «برگرد به اپ» را می‌بیند، کسی است که همین الان داخل اپ است.
برای بازگرداندن کاربر عملاً بی‌فایده است. در تنظیمات هم دقیقاً همین نوشته شده و
برچسب «فقط روی دستگاه» می‌خورد — به‌جای اینکه وانمود کنیم پوش داریم.

### با کلید: پوش واقعی، حتی وقتی اپ بسته است

کد سمت سرور آماده است (`server/push.js`). فقط کلید و یک زمان‌بند می‌خواهد.

```bash
npx web-push generate-vapid-keys
```

خروجی دو کلید است:

```
VITE_VAPID_PUBLIC_KEY=BFxxxx...     # عمومی — داخل باندل می‌رود، اشکالی ندارد
VAPID_PRIVATE_KEY=xxxx              # فقط سرور — این مثل رمز عبور است
VAPID_SUBJECT=mailto:you@example.com
```

اپ اشتراک‌ها را از همین حالا در `/api/push/subscribe` ذخیره می‌کند. یعنی روزی
که فرستنده را اضافه کنی، از قبل مخاطب داری.

سپس یک متغیر دیگر هم لازم است تا اندپوینت ارسال، عمومی و باز نباشد:

```
CRON_SECRET=یک-رشته-تصادفی-طولانی
```

فرستادن دیگر نیازی به اسکریپت دستی ندارد؛ اندپوینت آماده است:

```
POST /api/push/daily
Authorization: Bearer <CRON_SECRET>
```

روی Vercel کافی است `vercel.json` را با یک cron روزانه تنظیم کنی، یا از
GitHub Actions با `schedule` استفاده کنی. سرور خودش:

- متن روز را انتخاب می‌کند (۷ پیام چرخشی، تا مثل ربات گیرکرده نباشد)
- هر دستگاه را به **زبان خودش** پیام می‌دهد (اعلان در نوار سیستم رندر می‌شود،
  جایی که اپ دیگر فرصت ترجمه ندارد)
- اشتراک‌های مرده (پاسخ ۴۰۴/۴۱۰ یعنی اپ حذف شده) را همان‌جا پاک می‌کند، وگرنه
  برای همیشه جمع می‌شوند
- درخواست‌ها را دسته‌بندی می‌کند تا چند هزار اتصال هم‌زمان، هاست کوچک را نخواباند

وقتی پوش سرور فعال باشد، زمان‌بند محلی داخل اپ **خودش را کنار می‌کشد** تا کاربر
یک پیام را دو بار نگیرد.

**یک هشدار جدی:** اپی که زیاد نوتیفیکیشن می‌فرستد، اجازه نوتیفیکیشنش را از
دست می‌دهد — و بعد از آن نمی‌توانی حتی برای چیزهای مهم (نتیجه معامله، هشدار
امنیتی) به کاربر برسی. سقف روزی یک پیام تبلیغاتی در خود `lib/notify.js`
پیاده‌سازی شده، نه فقط به‌عنوان یک قصد خوب.

## ۴. چیزهایی که عمداً اضافه نشده‌اند

**کلید صرافی (Kraken، Nobitex، …).** این کلیدها می‌توانند پول واقعی جابه‌جا
کنند. در یک اپ تلگرامی که کاربر نهایی مستقیم با آن کار می‌کند جایی ندارند. اگر
روزی مسیریابی سفارش واقعی ساختی: کلید را در secrets manager بگذار نه `.env`
سرور اپ، سرویس ثبت سفارش را از لایه وب جدا کن، کلید را فقط trade-only و با
IP allowlist بساز، و قبل از اولین سفارش واقعی KYC/AML و سقف کاربری و لاگ ممیزی
داشته باش.

**API قیمت سهام واقعی.** توکنی که نماینده سهام باشد اوراق بهادار است و صدورش
مجوز می‌خواهد، نه API. صفحه سهام همین را می‌گوید و کاربر را به ناشران دارای
مجوز ارجاع می‌دهد.

## ۵. چک‌لیست قبل از انتشار

- [ ] `BLOB_READ_WRITE_TOKEN` — بدون این، رتبه‌بندی و اشتراک پوش با هر کولد استارت پاک می‌شود
- [ ] `VITE_API_BASE` — در بیلد APK **الزامی** است. اپ اندروید از `https://localhost` سرو می‌شود و مسیر نسبی `/api` به جایی نمی‌رسد
- [ ] `VITE_WALLETCONNECT_PROJECT_ID` — بدون این، اتصال کیف پول داخل تلگرام کار نمی‌کند
- [ ] `COINGECKO_API_KEY` — بدون این در ساعات شلوغ داده کند می‌آید
- [ ] آدرس‌های دریافت را در صفحه «ممیزی» داخل اپ چک کن و با آدرس‌های خودت مطابقت بده
- [ ] `GEMINI_API_KEY` — اختیاری؛ بدون آن راهنما از پایگاه دانش داخلی جواب می‌دهد
- [ ] VAPID — اختیاری؛ بدون آن اعلان‌ها محلی‌اند و اپ همین را می‌نویسد
