# ثبت FBT Swap در سایت‌های معرفی صرافی

> ⚠️ **آرشیوی:** این راهنما پیش از مهاجرت به `fbtswap.ir` نوشته شده و بعضی URLها/شرایط ثبت آن به‌روز نیستند. نقشهٔ اجرای فعلی در [SEO-VISIBILITY-FA.md](SEO-VISIBILITY-FA.md) است.

این سند دقیقاً می‌گوید کجا می‌توانیم ثبت شویم، کجا نمی‌توانیم، و **چرا** — با مدرک، نه حدس.

## اول: یک واقعیت که باید بدانی

سایت‌های لیستینگ دو دستهٔ کاملاً جدا هستند و ما فقط در یکی جا می‌شویم:

| نوع | مثال | ما جا می‌شویم؟ |
|---|---|---|
| **صرافی** (حجم معاملات خودش) | CoinGecko Exchanges، CoinMarketCap | ❌ **نه** |
| **دَپ / اپلیکیشن** | DappRadar، DefiLlama، Alchemy Dapp Store | ✅ **بله** |

### چرا CoinGecko Exchanges نه

آن صفحه‌ای که فرستادی (`coingecko.com/en/exchanges/manifest`) برای **صرافی‌هایی است که خودشان دفتر سفارش و حجم معاملات دارند**. آن‌ها باید:

- API عمومی داشته باشند که **حجم معاملات خودشان** را گزارش کند
- استخر نقدینگی و جفت‌ارز روی سرور خودشان داشته باشند

**ما هیچ‌کدام را نداریم و نباید داشته باشیم.** FBT Swap یک *واسط* است: سفارش را به PancakeSwap و Uniswap می‌فرستد. حجم مال آن‌هاست، نه ما. اگر ادعا کنیم حجم داریم، عدد دیگران را به نام خودمان زده‌ایم — که هم دروغ است هم باعث رد شدن درخواست می‌شود.

**این ضعف نیست.** MetaMask و Trust Wallet هم در آن لیست نیستند، به همان دلیل.

## جایی که واقعاً می‌توانیم ثبت شویم

### ۱. DappRadar — ساده‌ترین و مهم‌ترین

🔗 **https://dappradar.com/dashboard/submit-dapp**

بزرگ‌ترین دایرکتوری دَپ‌هاست و ترافیک واقعی می‌فرستد.

**قدم‌ها:**
1. حساب بساز و ایمیلت را تأیید کن
2. **Submit dApp** را بزن
3. پر کن:

| فیلد | مقدار |
|---|---|
| Name | `FBT Swap` |
| Category | `Exchanges` / `DeFi` |
| Website | `https://www.lawpoetics.ir` |
| Chains | BNB Chain, Ethereum, Polygon, Arbitrum, Base, Optimism, Avalanche |
| Description | از متن `og:description` در `index.html` بردار |
| Logo | `public/icon-512.png` |
| Email | `fbtswap@gmail.com` |

**نکته:** DappRadar آدرس قرارداد می‌خواهد تا فعالیت را ردیابی کند. ما قرارداد خودمان نداریم، پس **آدرس دریافت‌کنندهٔ کارمزد** را بده (`0xaf5C...24d6`) — این آدرس واقعاً روی زنجیره تراکنش دارد و قابل تأیید است.

**زمان بررسی:** حدود ۳ تا ۷ روز.

### ۳. DefiLlama — سخت‌تر، ولی معتبرترین

🔗 **https://docs.llama.fi/list-your-project/submit-a-project**

اینجا فرم نیست. باید **کد** بفرستی:

1. مخزن `DefiLlama/DefiLlama-Adapters` را fork کن
2. در `projects/` یک پوشه به نام `fbt-swap` بساز
3. یک adapter بنویس که TVL یا حجم را برگرداند
4. Pull Request بزن

⚠️ **صادقانه: ما هنوز آمادهٔ این نیستیم.** DefiLlama برای پروتکل‌هایی است که TVL دارند (پول قفل‌شده در قرارداد خودشان). ما پولی نگه نمی‌داریم، پس TVL ما صفر است.

**راه درست برایمان:** بخش **Fees & Revenue** آن‌هاست، نه TVL — چون ما کارمزد واقعی روی زنجیره می‌گیریم. ولی این نیاز به چند ماه تراکنش قابل ردیابی دارد. **بعد از اینکه حجم واقعی داشتیم.**

## کاری که من انجام دادم (و چرا لازم بود)

همهٔ این سایت‌ها **صفحهٔ تو را می‌خوانند** تا فرم را پر کنند. قبل از این کار، صفحهٔ ما این‌ها را نداشت:

| چیز | قبل | بعد |
|---|---|---|
| `<title>` | فقط «FBT Swap» | با کلمات کلیدی: DEX, Crypto Swap, 9 Chains |
| توضیحات | فقط فارسی | انگلیسی + فارسی |
| Open Graph | **هیچ** | کامل (عنوان، توضیح، تصویر) |
| کارت توییتر | **هیچ** | کامل |
| دادهٔ ساختاریافته | **هیچ** | JSON-LD نوع SoftwareApplication |
| `robots.txt` | **وجود نداشت** | هست، `/api/` را می‌بندد |
| `sitemap.xml` | **وجود نداشت** | هست |

**مهم‌ترینشان Open Graph بود:** بدون آن، هر لینکی که در تلگرام یا X می‌فرستادی فقط یک آدرس خشک بود، بدون عکس و بدون توضیح. این بزرگ‌ترین ضرر قابل اجتناب در نرخ کلیک است.
