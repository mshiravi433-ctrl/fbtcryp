# سولانا — راه‌اندازی دریافت کارمزد

> نسخهٔ ۱.۹.۰ · مرداد ۱۴۰۵

سواپ سولانا ساخته شد و کار می‌کند. ولی **تا وقتی دو مرحلهٔ پایین را انجام
ندهی، کارمزدی به تو نمی‌رسد.**

---

## ⚠️ مهم‌ترین نکتهٔ این فایل

Jupiter اگر «حساب معرف» نداشته باشی، **سواپ را انجام می‌دهد و کارمزد را صفر
می‌گذارد**. هیچ خطایی نمی‌دهد. هیچ هشداری نمی‌دهد.

یعنی یک نصب پیکربندی‌نشده **از بیرون دقیقاً شبیه یک نصب سالم است** — تا روزی
که موجودی را چک کنی و ببینی صفر است.

به همین دلیل در خود اپ یک پیام قرمز گذاشته‌ام که تا این کار انجام نشود نوشته:

> «دریافت کارمزد هنوز پیکربندی نشده: سواپ‌ها عادی کار می‌کنند ولی روی سولانا
> هیچ کارمزدی دریافت نمی‌شود.»

وقتی مرحله‌های زیر را انجام دادی، آن پیام خودش محو می‌شود.

## مرحلهٔ ۱ — ساخت حساب معرف (اجباری)

**بدون این، درآمد صفر است.**

### راه آسان: داشبورد

۱. برو به **<https://referral.jup.ag/>**
۲. کیف پول سولانا‌ات را وصل کن — همان که آدرسش این است:
   ```
   9Z4wtiosH7JMXhKg8JpUPDCtB5ZyM8vzby14HwDidgVz
   ```
۳. یک **referral account** بساز (اسمش را بگذار `fbt-swap`)
۴. آدرس حساب معرف را که می‌دهد **کپی کن** — به من بده یا خودت در مرحلهٔ ۳ بگذار
۵. برای **SOL** و **USDC** حساب توکن بساز (دکمهٔ Create token account)

### ⚠️ چرا باید برای هر توکن جدا حساب بسازی

Jupiter خودش تصمیم می‌گیرد کارمزد را با کدام توکن بردارد. ترتیب اولویتش:

```
۱. SOL   ۲. استیبل‌کوین‌ها (USDC/USDT)   ۳. توکن‌های استیک‌شده   ۴. بقیه
```

اگر برای آن توکن حساب نساخته باشی، **آن سواپ بدون کارمزد رد می‌شود**. با SOL
و USDC شروع کن — بیشتر سواپ‌ها را پوشش می‌دهند. بعداً می‌شود بقیه را اضافه کرد.

### هزینه

ساختن هر حساب چند صدم SOL هزینهٔ شبکه دارد (حدود ۰٫۰۰۲ SOL). یعنی برای شروع
حدود **۰٫۰۱ SOL** در کیف پولت لازم داری.

## مرحلهٔ ۲ — کلید API (اختیاری ولی توصیه می‌شود)

بدون کلید، اپ از مسیر عمومی Jupiter استفاده می‌کند که **۰٫۵ درخواست در ثانیه**
محدودیت دارد. برای یک نفر که دارد دکمه می‌زند کافی است؛ برای چند کاربر همزمان
نه.

۱. برو به **<https://developers.jup.ag/portal>**
۲. ثبت‌نام کن (رایگان)
۳. یک تیم بساز → **API key** بگیر
۴. پلن **Free** یک درخواست در ثانیه می‌دهد — برای شروع کافی است

| پلن | قیمت | سرعت |
|---|---|---|
| بدون کلید | رایگان | ۰٫۵ req/s |
| Free | رایگان | ۱ req/s |
| Developer | ۲۵ دلار/ماه | ۱۰ req/s |

با کاربر فعلی (صفر) پلن Free کافی است. وقتی کاربر واقعی آمد ارتقا بده.

## مرحلهٔ ۳ — گذاشتن مقادیر

### در Vercel (برای سایت)

`Settings → Environment Variables`:

| نام | مقدار | نوع |
|---|---|---|
| `JUP_REFERRAL_ACCOUNT` | آدرس حساب معرف از مرحلهٔ ۱ | Secret |
| `JUPITER_API_KEY` | کلید از مرحلهٔ ۲ | **Secret** |

> 🔴 `JUPITER_API_KEY` را **حتماً** Secret بگذار و **هرگز** با پیشوند `VITE_`
> نگذار. متغیرهای `VITE_` داخل فایل جاوااسکریپت مرورگر کامپایل می‌شوند و هرکسی
> می‌تواند بخواندشان. کلید لو رفته یعنی سهمیهٔ ما را دیگران خرج می‌کنند و
> سواپ برای کاربران واقعی می‌خوابد.

### در گیت‌هاب (برای اپ اندروید)

`Settings → Secrets and variables → Actions → Variables` (نه Secrets):

| نام | مقدار |
|---|---|
| `VITE_JUP_REFERRAL_ACCOUNT` | همان آدرس حساب معرف |

> این یکی Variable است نه Secret، چون آدرس حساب معرف عمومی است — روی زنجیره
> برای همه قابل دیدن است. فقط کلید API محرمانه است.

### ⚠️ یک کار دستی که فقط تو می‌توانی بکنی

توکن من اجازهٔ نوشتن در `.github/workflows/` را ندارد. یک خط را باید خودت
اضافه کنی، وگرنه **فایل APK بدون کارمزد ساخته می‌شود**.

فایل `.github/workflows/build-apk.yml` را باز کن، دنبال این خط بگرد:

```yaml
          VITE_FEE_RECIPIENT: ${{ vars.VITE_FEE_RECIPIENT }}
```

و **بلافاصله زیرش** این را اضافه کن:

```yaml
          VITE_JUP_REFERRAL_ACCOUNT: ${{ vars.VITE_JUP_REFERRAL_ACCOUNT }}
```

نسخهٔ کامل و درست این فایل در `ci/WORKFLOW-FIXED.yml` هست.

## چطور بفهمم کار می‌کند

**۱. در خود اپ:** صفحهٔ سولانا را باز کن. اگر پیام قرمز «دریافت کارمزد
پیکربندی نشده» رفته باشد، یعنی درست شده.

**۲. از سرور:**

```
https://www.lawpoetics.ir/api/solana/status
```

باید این را برگرداند:

```json
{ "configured": true, "feeReady": true, "referralAccount": "..." }
```

اگر `feeReady: false` است، هنوز حساب معرف ست نشده.

**۳. تست واقعی:** یک سواپ خیلی کوچک بزن (مثلاً ۰٫۰۱ SOL) و بعد در
[solscan.io](https://solscan.io) آدرس حساب معرفت را ببین — باید کارمزد رسیده
باشد.

## آنچه ساخته شد

| فایل | کار |
|---|---|
| `src/lib/solana.js` | کلاینت Jupiter، محاسبهٔ کارمزد، نگاشت خطا |
| `src/lib/solanaWallet.js` | اتصال و امضا با Phantom/Solflare/Backpack |
| `src/pages/SolanaSwap.jsx` | صفحهٔ سواپ |
| `server/solana.js` | پروکسی که کلید API را نگه می‌دارد |

**نکته‌های فنی که ممکن است لازمت شود:**

- کتابخانهٔ سولانا ۱۹ مگابایت است، پس **فقط وقتی صفحهٔ سولانا را باز کنی
  دانلود می‌شود**. سرعت بقیهٔ اپ تغییری نکرده — بررسی کردم که وارد چانک اصلی
  نشده باشد.
- پروکسی سرور فقط پارامترهای مشخصی را رد می‌کند. اگر کسی سعی کند
  `referralAccount` خودش را بفرستد تا کارمزد ما را بدزدد، **دور ریخته
  می‌شود** — تست کردم.
- تبدیل مقدار با ریاضی رشته‌ای انجام می‌شود نه ضرب اعشاری. `۸٫۳۱ × ۱۰⁹` در
  جاوااسکریپت می‌شود `8310000000.000001` که Jupiter ردش می‌کند. این باگ واقعی
  است و تستش را گذاشته‌ام.
