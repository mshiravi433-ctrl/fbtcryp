# 📻 رادیو FBT — پخش ۲ ساعت و ۱۵ دقیقه‌ای دنیای کریپتو

برنامهٔ فارسی رادیو FBT با آموزش کریپتو، گفت‌وگوی دو میزبان، موسیقی اختصاصی و فصل‌بندی قابل جست‌وجو. فایل پخش اصلی، هم در باکس رادیوی صفحهٔ اخبار و هم در پلیر مستقل استفاده می‌شود.

## فایل پخش

| فایل | مدت | توضیح |
|---|---:|---|
| `public/radio/fbt-radio-2h.mp3` | **۲:۱۵:۴۳** | استریم مونو، ۴۸ کیلوبیت؛ حدود ۴۹ مگابایت، با پشتیبانی از جابه‌جایی زمانی |
| `FBT_Radio_2Hours_chapters.txt` | — | فهرست کامل ۵۸ فصل با زمان شروع |
| `FBT_Radio_2Hours.cue` | — | فصل‌بندی قابل استفاده در پلیرهای سازگار با CUE |
| `playlist.m3u` | — | پلی‌لیست فایل پخش نهایی |
| `radio_fbt.html` | — | پلیر مستقل با فصل‌های قابل کلیک، دانلود و کاور؛ در خروجی وب با مسیر `/radio_fbt.html` منتشر می‌شود |
| `assets/radio/fbt-radio-cover.jpg` | — | کاور برنامه |

سرور محلی با پشتیبانی از Range:

```bash
python3 radio_server.py      # http://localhost:8000/radio_fbt.html
```

## ساختار برنامه

- **دو ساعت نخست:** نسخهٔ اصلی برنامه، آموزش و مصاحبهٔ سناریوییِ قبلی.
- **از ۲:۰۰:۰۰ به بعد:** ۱۰ فصل آموزشی تازه، به‌علاوهٔ موسیقی آغاز، چهار میان‌برنامهٔ تازه و موسیقی پایان.
- **میزبانی:** هر ده فصل تازه با نوبت‌های جداگانهٔ امیر و رها میکس شده‌اند؛ نام میزبان‌ها و زمان فصل‌ها در متادیتای اپ و پلیر مستقل هماهنگ است.
- **مدت فعلی:** ۱۵ دقیقه و ۴۳ ثانیه به برنامه افزوده شده؛ فایل فعلی ۲:۱۵:۴۳ است.

### موضوع‌های تازه

1. تاریخچهٔ کریپتو و مسیر بیت‌کوین تا قراردادهای هوشمند
2. شناخت ترید و خواندن نمودار شمعی
3. تفاوت شبکهٔ Venom با اکوسیستم dYdX
4. کاربرد سواپ، اسلیپیج و معنای سیگنال
5. تفاوت کیف‌پول با WalletConnect و نکته‌های نگهداری امن
6. تفاوت شبکه‌ها و انتقال آزمایشی کم‌ریسک
7. فارم، شرایط استفاده، بازده متغیر و ریسک پروتکل
8. FBT جهانی و Smart Money؛ داده به‌عنوان سرنخ، نه پیش‌گویی
9. استفاده از فیوچرز، انواع سفارش و تب‌های دفتر سفارش، Tape، Funding و Risk
10. سفارش خودکار، حد سود/ضرر، ماشه و محدودیت اجرای سفارش

### موسیقی

در بخش تازه، برای هر گفت‌وگو یک بستر موسیقی جدا و برای آغاز، میان‌برنامه‌ها و پایان قطعه‌های مستقل ساخته شده است؛ **هیچ‌یک از موسیقی‌های تازه در این بخش تکرار نمی‌شود**. همهٔ این قطعه‌ها با موتور سینتی‌سایزر `radio_build/music_engine.py` از صفر تولید شده‌اند. آهنگ تجاریِ مشهور وارد استریم نشده تا برنامه به مجوز و حق‌نشر موسیقی ثالث وابسته نباشد.

## پلیر داخل اپ

- پلیر در صفحهٔ اخبار فقط برای رابط فارسی نمایش داده می‌شود و با یک `<audio>` سراسری، هنگام جابه‌جایی بین صفحه‌ها ادامه پیدا می‌کند.
- فصل‌های آموزشی تازه از داخل باکس قابل انتخاب‌اند؛ زمان نهایی از فرادادهٔ فایل خوانده می‌شود.
- مسیر فایل همان‌مبدأ است و امکان Range/seek را حفظ می‌کند.
- برای نسخهٔ تازه، URL با شناسهٔ نسخه‌دار `?v=20261127-dialogue-v5` فراخوانی می‌شود تا کش فایل قبلی را برنگرداند.

| فایل | نقش |
|---|---|
| `src/components/FbtRadioBox.jsx` | باکس فارسی، کنترل‌ها و فصل‌های منتخب |
| `src/lib/fbtRadioMetadata.js` | مدت و زمان فصل‌های برجستهٔ پلیر |
| `src/lib/fbtRadioEngine.js` | یک عنصر صوتی سراسری، کنترل پخش و Range seek |
| `src/store/useFbtRadioStore.js` | وضعیت پخشِ پایدار در ناوبری |
| `src/styles/fbt-radio.css` | پوستهٔ رادیو و کنترل‌ها |
| `radio_build/dialogue_2026-11-fa-v2.md` | متن گفت‌وگوی دوصدایی و نوبت‌های بازضبط‌شده |
| `radio_build/append_dialogue.py` | میکس بسترهای یکتا و افزودن فصل تازه به استریم |

## شفافیت و ریسک

گفت‌وگوی تازه **سناریوی آموزشی دو میزبان استودیویی است، نه مصاحبهٔ زنده یا مهمان واقعی**؛ در فایل صوتی فعلی، صدای اصلی بین فصل‌ها عوض می‌شود. این برنامه توصیهٔ سرمایه‌گذاری نیست. سیگنال، بازده فارم، اهرم و سفارش خودکار هیچ‌کدام سود را تضمین نمی‌کنند؛ شرایط شبکه و پروتکل را پیش از هر امضا یا انتقال بررسی کنید.

## بازتولید میکس افزوده‌شده

ورودی‌های صدای استودیویی نگه‌داری می‌شوند در `radio_build/generated/` و عمداً وارد Git نمی‌شوند؛ متن برنامه و پارامترهای موسیقی در مخزن هستند. با آماده‌بودن کلیپ‌های گفتار، میکس افزوده را این‌طور می‌توان دوباره ساخت:

```bash
python3 -m venv /tmp/radvenv
/tmp/radvenv/bin/pip install numpy scipy imageio-ffmpeg
/tmp/radvenv/bin/python radio_build/append_dialogue.py
```

اسکریپت یک نسخهٔ پایهٔ دو ساعته را در `/tmp` نگه می‌دارد، بخش تازه را با ۱۶ قطعهٔ موسیقی یکتا میکس می‌کند، فایل MP3 را با همان نرخ استریم می‌سازد و زمان فصل‌های افزوده را در `radio_build/generated/dialogue-chapters.json` می‌نویسد.
