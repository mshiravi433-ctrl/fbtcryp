# FBT Intent OS — Cinematic Product Film

Open `index.html` in a browser (or visit `/intent-os-film/` on the site).

Click **PLAY FILM**. Native English narration plays across 10 scenes with cinematic stills.

This is a web-based product film (images + professional VO), not a 4K 24fps encoded MP4. True 10-minute UHD documentary production requires a film pipeline (Cinema 4D / After Effects / DaVinci). The script, voice, and visual direction are captured here.
